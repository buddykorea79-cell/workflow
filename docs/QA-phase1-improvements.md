# 1차 업무 흐름 개선 검증

기준일: 2026-11-05. 대상은 프로토타입이며 실제 Neon 업무 데이터는 초기화하거나 시험 데이터로 교체하지 않았습니다.

## 구현 범위

- 업무분장 확정 후에도 담당자·지원담당자가 생산 문서와 집행 내역을 `수행 기록 입력`으로 저장할 수 있습니다. 업무 기준·법령·담당 역할·예산 총액은 그대로 잠기며 변경 전후 기록을 남깁니다.
- 확정 부서에 공통업무를 접수할 수 있습니다. 부서 내 배정과 업무분장 변경은 기존 재작성 허용 절차를 따릅니다.
- 중앙 제출기한과 내부 수행 일정을 구분합니다. 내부 일정을 늦춰도 중앙 기한을 기준으로 지연을 표시합니다.
- 인수인계 요청 후 진행률·메모·수행 기록·회차 일정이 변경되어도 승인할 수 있습니다. 업무 정의나 담당 역할이 달라지면 재요청해야 합니다.
- 인계 전 작성한 반기 성과는 원작성자가 보완할 수 있고, 제출한 단위업무·배점을 보존합니다. 후임자의 업무 접근 권한은 부여하지 않습니다.
- 완료한 절차 단계의 실행 기준은 변경할 수 없으며, 지원 업무 일정과 본인의 이전 부서 인수인계 이력을 조회할 수 있습니다.
- 근거 파일 교체 시 새 본문과 기존 본문을 비교·선택합니다. 기존 본문을 유지하려면 내용 일치를 명시적으로 확인해야 합니다.

## 실제 Neon 연결 및 파일 시험

아래 시험은 로컬 `.env.local`에 연결된 프로젝트를 대상으로 수행했습니다. 비밀값·서명 URL은 출력하지 않았습니다.

| 시험 | 결과 |
| --- | --- |
| `npm run neon:check` | DB 연결 성공, 워크스페이스 리비전 29 조회 |
| 기존 데이터 조회 | 사용자 33명, 부서 3개, 단위업무 18개, 세부업무 24개, 회차 18개 확인 |
| Storage 연결 | 설정된 버킷 접근 성공, CORS 규칙 1개 확인 |
| `npm run neon:files:check -- --origin https://on-ieum.vercel.app` | 실제 서비스 origin의 CORS 사전 요청 통과 |
| 임시 텍스트 파일 업로드 | 서명 PUT 업로드 성공 |
| 파일 읽기 및 다운로드 | 저장한 바이트와 동일, 다운로드 응답의 첨부 헤더 확인 |
| 시험 후 정리 | 이번 시험에서 만든 임시 객체만 삭제, 워크스페이스 데이터 변경 없음 |

DB의 첨부파일 메타데이터는 점검 시점에 0개였습니다. 따라서 기존 첨부파일 전체의 무결성을 검증했다는 의미는 아닙니다. 이 시험은 실제 Storage 연결·CORS·서명 업로드/다운로드 경로를 확인하며, 배포 앱의 로그인부터 파일 첨부 화면까지 직접 조작한 종단간 시험과는 구분합니다. 설정 위치와 재점검 명령은 [Neon 설정 안내](PROTOTYPE-NEON-SETUP.md)를 참고하세요.

## 자동 검증

- 1차 구현 기준 `npm test`: **236개 통과**. 수행 기록 권한·위조 입력·확정 상태, 공통 기한, 인수인계 충돌, 성과 원작성자 및 배점, 첨부파일 본문 교체 회귀를 포함합니다.
- 1차 구현 기준 `npm run build`: **성공**. Next.js 빌드와 TypeScript 검사를 통과했습니다.
- 조직·잔여 역할 추가 개선과 빈 회차 기간의 중앙 기한 보정까지 포함한 최종 `npm test`: **256개 전부 통과**했습니다.
- 추가 개선의 `npm run build`도 **성공**했습니다. 타입 검사와 전체 페이지 생성이 완료되었습니다.
- 테스트는 메모리 데이터와 격리 저장소를 사용했습니다. 파일 점검은 Origin·허용 헤더·PUT 응답 CORS 검사까지 보강한 뒤 다시 통과했습니다.

## 화면 검증

격리된 로컬 저장소 `.qa-data/phase1-preview`와 `127.0.0.1:3001`에서 시험했습니다.

- 확정된 부서의 담당자가 `수행 기록 입력`에 진입하면 법령은 잠기고 생산 문서는 편집됩니다.
- 기존 첨부파일을 다른 파일로 교체하면 본문 선택 안내가 나타나며, 일치 확인 전에는 기존 본문 유지 버튼이 비활성화됩니다.
- 본문을 비우고 새 내용을 입력해 저장하면 변경 이력 1건과 작성자·시간이 표시됩니다.
- 업무를 인계하여 현재 세부업무 접근이 없는 원작성자가 `성과 · 평가 → 성과 수정`에서 기존 성과를 보완하고 저장하는 것을 확인했습니다.
- 같은 원작성자가 업무 비중 50점을 설정해 제출한 뒤, 부서장이 46/50점으로 평가를 확정하는 것까지 확인했습니다.
- 추가 조직 화면은 [2-A QA](QA-phase2-organization.md)를 참고하세요. 신규 직원 등록→전보→비활성→모바일 재활성, 미인계 책임이 있는 전보 차단, 변경 로그·시연 계정 목록 갱신을 확인했습니다.
- `남은 역할 정리`에서 공통업무 총괄 2건을 선택하고 후임 지정→요청→해당 부서장 승인→이관 완료·로그 표시를 확인했습니다. 역할 선택 순서 안내와 카드의 역할 건수 표시도 보완했습니다.
- 390px 화면에서 조직 변경 폼과 역할 승인 상세의 가로 넘침이 없고 저장 버튼에 접근할 수 있었습니다.
