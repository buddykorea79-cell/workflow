# 온이음 v0.7.0 검증 기록

검증일: 2026-10-31

## 변경 내용

- 세부업무의 절차·일정에 현재 회차, 다음 회차 시작, 지난 회차 조회를 추가했다.
- 검토·승인을 포함한 모든 절차가 완료되면 담당자 또는 관리자가 다음 회차를 시작한다.
- 회차명과 새 시작일·마감일, 절차별 일정을 지정한다. 시작일을 바꾸면 이전 일정의 간격을 유지해 날짜를 제안하며 개별 수정도 가능하다.
- 새 회차의 완료 상태·체크리스트·실행 결과를 초기화하고, 이전 회차의 절차·일정·결과·완료자·완료 시각·메모를 읽기 전용 기록으로 보존한다.
- 업무 일정, 대시보드, 공통업무 진행률에 현재 회차의 일정과 진행 상태를 반영한다.
- 업무분장이 확정된 상태에서도 실행 회차를 이어갈 수 있다. 미완료 회차, 중복 시작, 확정 전 업무 개정안, 잘못된 일정과 권한은 서버에서 차단한다.

## 브라우저 검증

- 격리 데이터에서 송주무관의 ‘정보화사업 정산 증빙 정리’ 1회차를 검토·승인까지 완료했다.
- 완료된 회차에서 ‘다음 회차 시작’이 표시되고 완료 체크박스가 잠기는 것을 확인했다.
- 새 회차명 ‘12월 정산 업무’와 시작일 2026-12-01을 입력했다. 절차별 일정이 12/01~04, 12/04~07, 12/07~10, 12/10~13으로 이동하고 마감일이 12/13으로 제안되었다.
- ‘새 일정으로 회차 시작’ 후 현재 2회차, 진행률 0%, 새 일정이 즉시 표시되었다.
- ‘지난 회차’에서 완료된 1회차의 절차 4건, 원래 11월 일정, 완료자·완료 시각·체크리스트·결과·메모를 확인했다. 이전 기록의 수정·저장 기능은 표시되지 않았다.
- 실제 앱 127.0.0.1:3000을 v0.7.0 운영 빌드로 재실행했다. 기존 미완료 업무에서 현재 1회차와 완료 후 다음 회차 안내가 표시됨을 확인했다.

화면 기록: `artifacts/work-cycles-v0.7.0.png`. 격리된 검증 데이터의 2회차와 지난 1회차 화면이며, 실제 업무를 임의로 완료하거나 초기화한 결과가 아니다.
