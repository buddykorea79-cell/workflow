# 온이음 인수인계 사용 안내

왼쪽 **인수인계** 메뉴에서 인사이동에 따른 업무 보관, 새 담당자 배정 요청, 부서장 승인과 처리 이력을 관리합니다. 프로토타입의 기존 부서·사용자 목록을 사용하며, 인수자는 해당 부서에 등록된 활성 개인 담당자·팀장·부서 담당자 중에서 선택합니다.

## 두 가지 처리 흐름

| 상황 | 처리 순서 | 담당자 변경 시점 |
| --- | --- | --- |
| 갑작스러운 인사이동으로 후임자가 아직 없음 | 부서 담당자 또는 관리자가 긴급 인사이동 등록 → 업무 전체를 부서 담당자에게 보관 → 새 담당자에게 전부·일부 배정 요청 → 부서장 승인 | 부서 담당자 보관은 즉시, 새 담당자 배정은 부서장 승인 시 |
| 새 담당자가 이미 부서원으로 등록되어 있음 | 인계자 또는 부서 담당자·관리자가 인수인계 요청 → 부서장 승인 | 부서장 승인 시 |

부서장이 승인하면 배정이 바로 적용됩니다. 이후 인수자가 별도로 수락하는 단계는 없습니다. 승인 대기 중에는 현재 담당자가 유지됩니다.

## 갑작스러운 인사이동

1. 부서 담당자 또는 관리자 계정으로 **인수인계 → 긴급 인사이동**을 엽니다. 관리자는 먼저 대상 부서를 선택합니다.
2. 인사이동한 인계자와 업무를 보관할 해당 부서의 활성 부서 담당자를 선택합니다. 인계자가 비활성 계정이거나 이미 다른 부서로 이동했더라도 원래 부서에 남아 있는 업무를 기준으로 처리할 수 있습니다.
3. 전체 대상 단위업무·세부업무를 확인하고 인사이동 사유를 입력합니다.
4. 이관을 실행하면 대상 업무가 부서 담당자에게 즉시 이동하고 **인수인계 이력**에 남습니다. 인계자의 로그인이나 부서장의 사전 승인은 필요하지 않습니다.
5. **부서 보관 업무**에서 남은 업무를 확인하고 새 담당자에게 배정을 요청합니다. 이 배정은 부서장 승인 후 적용됩니다.

긴급 이관 대상은 해당 부서에서 인계자가 소유한 삭제되지 않은 단위업무와 인계자가 정담당인 유효한 세부업무입니다. 휴지통의 업무와 보관 처리된 세부업무는 제외합니다. 단위업무를 다른 직원과 함께 사용하고 있다면 다른 직원이 담당하는 세부업무의 담당자는 유지합니다.

선택한 업무에 진행 중인 인수인계가 있으면 긴급 이관 시 중복된 요청을 취소하고 그 사유를 기록합니다. 새 담당자 배정은 긴급 이관된 상태를 기준으로 다시 요청합니다.

## 전체 또는 일부 업무 배정 요청

1. **인수인계 요청**을 엽니다. 개인 담당자·팀장은 본인 업무를, 부서 담당자·관리자는 관리 범위 내 직원의 업무를 선택할 수 있습니다.
2. 인계자와 같은 부서의 **새 담당자**를 선택합니다. 부서 보관 업무를 재배정할 때에는 현재 보관 중인 부서 담당자가 인계자가 됩니다.
3. 단위업무 전체를 넘기려면 해당 단위업무를 선택합니다. 그 안에서 인계자가 담당하는 세부업무가 함께 이동합니다. 일부만 넘기려면 필요한 세부업무만 선택합니다.
4. 대상 목록과 건수를 확인하고 사유·인계 내용을 작성한 뒤 **부서장 승인 요청**을 누릅니다.
5. **승인 대기**에서 상태를 확인합니다. 요청자는 승인 전에 **요청 취소**를 사용할 수 있습니다.

일부 세부업무만 이동할 때에는 새 담당자의 단위업무 묶음으로 연결되며, 선택하지 않은 업무는 기존 담당자에게 남습니다. 전체 단위업무 이관에서는 단위업무의 소유자가 변경됩니다. 진행 중인 회차도 새 담당자가 이어서 수행할 수 있도록 연결됩니다.

이전 인수인계에서 업무 기준의 담당자만 바뀌고 진행 회차의 담당자는 그대로 남은 경우에는 **이전 배정에서 남은 진행 회차**에 표시됩니다. 이 회차만 선택해 인수인계를 요청할 수 있으며, 부서장 승인 후 선택한 회차의 수행 담당자만 변경됩니다. 세부업무의 현재 소유자와 다음 회차의 담당 기준은 유지됩니다. 긴급 인사이동 때에도 이런 미완료 회차를 부서 담당자가 함께 보관하고, 이후 같은 승인 절차로 새 담당자에게 재배정할 수 있습니다.

한 업무에 승인 대기 요청을 중복으로 만들 수 없습니다. 여러 직원에게 나누어 배정하려면 업무 범위가 겹치지 않게 각각 요청합니다.

## 부서장 승인과 반려

1. 해당 부서의 부서장 계정으로 **인수인계 → 승인 대기**를 엽니다.
2. **상세 보기**에서 인계자, 새 담당자, 단위·세부업무 범위와 사유를 확인합니다.
3. **승인하여 배정**을 누르면 현재 담당자와 업무 연결이 변경되고 완료 이력이 남습니다.
4. 수정이 필요하면 **반려**를 선택하고 사유를 입력합니다. 요청자는 반려 사유를 확인한 뒤 새 요청을 작성합니다.

최종 승인·반려는 해당 부서의 활성 부서장만 처리합니다. 관리자 계정도 이 승인을 대신할 수 없습니다. 승인 시점에 인수자의 재직·소속 또는 업무 소유 관계가 달라졌으면 적용을 중단하므로, 현재 상태를 확인해 요청을 다시 작성합니다.

부서 업무분장이 확정된 상태에서도 인사이동은 이 별도 절차로 처리합니다. 이전 확정본은 보존하며, 일반 업무 내용·근거·절차 기준을 수정하는 경우에는 기존 재작성 허용 절차를 이용합니다.

## 역할별 메뉴와 범위

| 역할 | 이용 범위 |
| --- | --- |
| 개인 담당자·팀장 | 본인 업무 인계 요청, 본인과 관련된 승인 대기·인수인계 이력 확인, 본인이 요청한 대기 건 취소 |
| 부서 담당자 | 소속 부서 긴급 이관, 직원 간 인계 요청, 부서 보관 업무의 전체·일부 재배정 요청, 부서 이력 확인 |
| 부서장 | 소속 부서 승인·반려, 부서 보관 업무와 처리 이력 확인 |
| 관리자 | 대상 부서 선택, 긴급 이관과 인수인계 요청 지원, 부서별 현황·이력 확인. 최종 승인은 해당 부서장이 처리 |
| 공통업무 담당 추가 권한 | 본래 조직 역할의 인수인계 범위를 적용. 추가 권한 자체로 다른 직원의 인수인계를 승인하지 않음 |

## 남는 기록과 이어지는 업무

**인수인계 이력 → 상세 보기**에서 요청·긴급 이관·승인·반려·취소·적용 내역을 확인합니다. 대상 업무의 당시 이름과 인계자·인수자, 처리자, 처리 시각, 사유가 남으므로 업무 이름이나 담당자가 이후 바뀌어도 당시 인계 내용을 확인할 수 있습니다.

- 단위업무와 세부업무의 현재 소유·담당 관계, 진행 중인 회차 담당자, 연결된 공통업무의 현재 배정이 반영됩니다.
- 업무 내용, 관련 근거·파일, 절차, 일정과 기존 수행 기록은 이어집니다.
- 완료된 회차, 체크·결과 기록의 기존 수행자, 성과 작성자와 이전 업무분장 확정본은 보존합니다.
- 요청·승인 등 처리 내역은 인수인계 이력과 변경 기록에 남습니다. 반려·취소된 요청도 이력으로 확인할 수 있습니다.

현재 기능은 같은 부서 안에서 업무를 이어주는 흐름입니다. 새 직원은 먼저 해당 부서의 활성 구성원으로 등록되어 있어야 인수자 목록에서 선택할 수 있습니다.
