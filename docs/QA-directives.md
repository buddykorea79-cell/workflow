# 지시사항·월별 실적·기획팀 총괄 검증 · 2026-11-01

## 구현 범위

- 공통업무 만들기의 지시사항에 지시자(장관·차관·실장·국장)와 지시일자 입력.
- 개인 단위업무 등록을 마친 현재 담당자가 지시일자가 속한 월부터 현재 월까지 실적·다음 계획·특이사항을 기록.
- 같은 배정의 같은 월은 기존 실적을 수정하며 다른 월의 기록은 보존. 완료한 업무는 월별 실적을 조회만 가능.
- 기획재정담당관실 기획팀은 작성자와 배포 대상에 관계없이 장·차관 지시사항의 부서별 현황과 월 실적을 조회하고 추가 배포·지시정보 관리를 수행.
- 총괄 권한으로 다른 부서의 세부업무 본문을 열거나 담당자를 대신하여 실적을 작성할 수 없음.

## 실제 검증 결과

- `npm run typecheck`: 통과.
- `npm test`: 전체 165개 통과.
- `npm run build`: 운영 빌드 성공.
- `node tests/http-directives.mjs http://127.0.0.1:3001`: 아래 12개 검증 묶음 통과.

1. 새 지시사항의 지시자·지시일자 필수 입력, 지원하지 않는 지시자와 존재하지 않는 날짜 거절.
2. 지시정보 저장과 대상 부서별 세부업무 자동 생성.
3. 일반 공통업무 관리 권한이 없는 기획팀 구성원도 장관 지시사항 전체를 조회하며 타 부서 세부업무 본문은 받지 않음.
4. 수신 부서 구성원은 자기 부서 배정만 조회하며 다른 작성자의 지시사항 관리 권한은 얻지 않음.
5. 기획팀 총괄 권한은 장·차관 지시사항에 한정되고 일반 공통업무와 국장 지시사항에는 확대되지 않음.
6. 기획팀의 지시정보 수정·추가 부서 배포와 지시자 재분류를 통한 권한 우회 차단.
7. 부서 담당자 → 팀장 → 개인 담당자 → 내 단위업무 등록 이후 월별 실적 입력.
8. 현재 수행 담당자만 실적 입력 가능. 미래 월·지시 이전 월·잘못된 월과 빈 실적 거절.
9. 같은 월 실적 수정 시 중복 생성하지 않고 이전 월 기록 보존.
10. 재로그인 후 기획팀의 월별 기록 조회와 타 부서 업무 본문 접근 제한 유지.
11. 부서 업무분장 확정 후에도 진행 중인 지시사항의 월별 실적 저장 가능.
12. 절차 완료 후 월별 실적 추가·수정 거절, 완료 전 기록 보존.

- 혁신행정담당관실 임주무관의 세부업무에서 월별 실적 탭이 업무 성과 탭 앞에 표시됨. 추진 실적과 향후 계획을 입력·저장하여 저장 완료 안내와 1개월 이력을 확인함.

## 재실행

기존 검증 저장소의 화면을 다시 확인할 때 다음 명령으로 격리 서버를 실행한다.

```powershell
$env:IEUM_DATA_DIR = 'D:\Workflow-Project\.qa\directive-management-20261101'
npm run start -- --port 3001
```

전체 HTTP 검증을 처음부터 실행할 때는 새 격리 경로를 만든 후 서버를 실행한다. 같은 3001 포트에서 실행 중인 검증 서버가 있다면 먼저 종료한다.

```powershell
$qaDirectivePath = Join-Path (Get-Location) ('.qa/directive-management-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $qaDirectivePath | Out-Null
Copy-Item -LiteralPath '.data/workspace.json' -Destination (Join-Path $qaDirectivePath 'workspace.json')
$env:IEUM_DATA_DIR = $qaDirectivePath
npm run start -- --port 3001
```

별도 터미널에서 실행한다.

```powershell
node tests/http-directives.mjs http://127.0.0.1:3001
```

HTTP 검증 스크립트는 루프백 주소와 3001 포트만 허용한다. Windows 실행 환경에서 로컬 네트워크 접근 제한이 발생하면 검증 서버와 HTTP 명령을 로컬 네트워크 접근이 가능한 동일한 권한 환경에서 실행해야 한다.
