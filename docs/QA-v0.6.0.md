# 온이음 v0.6.0 검증 기록

검증일: 2026-10-31

## 변경 내용

- 부서장 업무 홈과 업무분장 화면에 팀 → 직원 → 단위업무 → 세부업무를 기본 전체 펼침 표로 표시.
- 업무 제목 및 상세 보기에서 업무 내용·절차·예산·근거 상세로 연결. 부서장 상세는 보기 모드로 시작.
- 반기별 개인 성과를 단위업무별로 모아 조회하고 세부업무의 성과 내용과 증빙을 함께 표시.
- 개인이 활성 단위업무의 배점 합계를 50점으로 저장하고, 부서장이 각 배점 안에서 점수와 의견을 입력.
- 확정 평가의 배점·업무명·성과 근거를 스냅샷으로 보존. 이전 단위업무의 성과는 참고 자료로 구분.
- 인수인계 후에도 원작성자의 성과를 보존하고 작성자별로 같은 반기의 성과 제출을 구분.

## 평가 규칙

- 배점과 평가는 반기별로 관리한다. 모든 활성 단위업무가 배점표에 포함되며 0점도 허용한다.
- 성과가 없는 단위업무는 0점만 입력할 수 있다. 평가를 확정하려면 배점 대상 단위에 제출된 성과가 적어도 하나 있어야 한다.
- 평가 확정 후 같은 반기의 배점·성과·평가 결과를 덮어쓰지 않는다.
- 비율·평균·점수 지표는 합산하지 않고 개별 값을 표시한다.
- 부서장 권한은 자신의 부서에서 작성된 성과에 적용되며, 관리자만 전체 범위의 평가를 조회한다.
