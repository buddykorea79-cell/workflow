# 업무분장표 부서 조회·AI 생성 안정성 검증

검증일: 2026-11-09, 로컬 소스 기준.

## 반영 내용

- 업무분장표는 관리자 포함 모든 역할에서 소속 부서만 처음 표시합니다. 기존 담당자·단위업무·세부업무·업무대행자 4열 형식을 유지합니다.
- 부서 선택을 활성화해 다른 부서를 조회하고, 현재 부서·팀·이름 조건으로 Excel/PDF를 내려받습니다. 초기화하면 소속 부서로 돌아갑니다. 관리자의 명시적 전체 부서 선택은 유지합니다.
- 다운로드 API에서 부서 조건을 생략하면 소속 부서를 사용합니다. 일반 역할의 `departmentId=all`도 소속 부서로 해석하며, 명시적으로 선택한 다른 부서는 허용합니다.
- 다른 부서에 공유하는 정보는 분장표용 제목·담당 관계입니다. 상세 업무 본문·첨부파일·변경 권한은 기존 접근 제어를 유지합니다.
- AI 단위·세부업무 생성, 업무 설명 초안, 절차 생성에 경과 시간·약 3분 대기 안내·취소 기능을 제공합니다.
- 동기 중복 클릭을 막고, 취소한 요청의 뒤늦은 응답과 종료 처리가 새 요청을 덮어쓰거나 대기 상태를 해제하지 않도록 합니다.
- 실패·취소 시 입력과 검토 초안을 보존합니다. 생성 중 내용이 바뀌면 검토 없이 덮어쓰지 않습니다. 저장 결과를 받지 못했을 때 같은 등록 요청으로 결과를 확인하는 기존 흐름은 유지합니다.
- 파일 읽기는 개별 추출 요청에 브라우저 대기 제한을 두며, 업무등록에서 읽기를 중단해도 완료된 본문은 유지합니다.

## 처리 시간과 서버 제어

| 구분 | 설정 |
|---|---:|
| 생성 API 전체 서버 예산 | 180초 |
| 브라우저 생성 응답 대기 | 190초 |
| 세 생성 경로의 Next.js `maxDuration` | 200초 |

인증·요청 본문 읽기·자료 준비·모델 조회·응답 읽기와 필요한 응답 보정은 같은 서버 기한을 공유합니다. 사용자 취소는 HTTP 499 / `AI_CANCELLED`, 시간 초과는 HTTP 504 / `AI_TIMEOUT`으로 구분합니다. 제한 시간이나 연결 오류 뒤에 자동으로 유료 생성 요청을 반복하지 않습니다. 설명·절차 응답의 구조·인용 검증을 위한 기존 최대 1회 보정은 같은 기한 안에서 수행합니다.

중단할 수 없는 파일 파서나 외부 작업이 남아 있으면 HTTP 응답 대기는 종료하되, 원래 작업이 끝나기 전까지 해당 서버 프로세스의 사용자별 잠금을 유지합니다. 중복 잠금은 Node 프로세스 메모리 기준이며 다중 인스턴스 공용 잠금은 추가하지 않았습니다. 배포 플랫폼이 200초 실행을 지원해야 하며, 이번 검증은 운영 배포의 제한 시간이나 실제 모델 응답 품질을 검증한 것은 아닙니다.
