# 업무분장표 절차도 보기 검증

검증일: 2026-11-09.

## 사용 방법과 표시 범위

업무분장표의 세부업무 제목 옆 **절차도 보기**를 누르면 현재 저장된 업무 기준의 절차를 팝업으로 확인합니다. 단계명·담당 역할·선행 관계와 실제 배정된 담당자 이름을 표시하며, **확대 보기**, 이동·확대/축소, **절차 목록으로 보기**를 사용할 수 있습니다. 기본 소속 부서, 다른 부서 선택, 기존 4열과 Excel/PDF 다운로드 조건은 유지합니다.

모든 활성 로그인 역할은 분장표에서 조회할 수 있는 업무의 절차도를 볼 수 있습니다. 서버는 요청할 때마다 분장표 노출 여부를 확인합니다. 삭제·보관 업무, 삭제된 단위업무, 미등록 공통업무 등 분장표에서 제외된 업무의 절차도는 반환하지 않습니다.

응답은 업무·단위·부서 이름, 절차의 `id/title/role/dependsOn`, 역할별 담당 표시만 포함합니다. 상세 설명·첨부·근거·예산·성과·날짜·완료 상태·과거 수행 기록은 포함하지 않습니다. 본문과 첨부의 기존 접근 권한은 유지합니다. 원본 업무에 쓰기를 하지 않는 조회 화면이며, 회차 진행 실적은 표시하지 않습니다.

## 안정성과 화면

- 모달은 즉시 열고 내용은 지연 로딩합니다. 첫 로딩 중에도 닫을 수 있습니다.
- 조회 제한 시간은 30초이며, 오류 안내와 **다시 불러오기**를 제공합니다.
- 창 닫기·다른 업무 열기 때 이전 요청을 취소하고 늦은 응답을 무시합니다.
- 저장된 절차가 없으면 빈 상태 안내를 표시합니다.
- 데스크톱에서는 팝업 폭 최대 1,200px·도표 높이 400px, 모바일에서는 도표 높이 320px로 표시합니다.
- 확대 창과 원래 창을 Escape로 차례로 닫으면 분장표의 버튼으로 초점이 돌아갑니다.

## 검증 결과

- 전체 회귀 테스트 870개 통과 후 추가된 UI 테스트 3개 별도 통과: 총 873개, 실패 0개.
- 타입 검사 및 최종 배포용 빌드 통과.
- 격리 로컬 브라우저 9항목 통과: 최소 API 응답·상세 권한 유지, 기존 4열, 절차도·목록, 확대·Escape·초점 복귀, 다른 부서의 실제 담당자, 390px 모바일 넘침 없음, 오류 재시도, 늦은 응답 무시, 빈 절차, 런타임 오류 유무.
- API 테스트는 모든 역할의 타부서 조회, 비활성 사용자 거부, 숨겨진 업무 거부, 첨부 다운로드 403, writer lock 상태의 조회와 저장 파일 불변을 포함합니다.
- 브라우저는 `.qa/division-procedure-data`의 격리 저장소를 사용했습니다. 운영 데이터 변경 및 AI 호출은 없습니다.
