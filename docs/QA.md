# 최종 로컬 검증 기록

검증일: 2026년 10월 31일, Asia/Seoul.

## 자동 검사

- TypeScript 검사 성공.
- 도메인·권한·회귀 테스트 39개 성공. 전체 AT01–AT53 통과를 뜻하지 않는다.
- `npm run build` 성공. Windows 환경의 Turbopack 프로세스 오류를 피하기 위해 공식 Next.js Webpack 빌드를 사용한다.
- 홈과 워크스페이스 API HTTP 200 확인.

## 브라우저 확인

- 업무 생성 폼에 가상 업무 `월간 협업 현황 정리`를 입력하고 서버 저장 성공, 목록·9칸 관리카드에서 저장 내용 확인.
- 업무 상세의 워크플로 편집 화면과 역할별 절차 표시 확인.
- `주간 간부회의 운영 인수인계`의 세 가지 확인 항목을 각각 저장한 뒤 지정 인수자 김민서로 수락. 효력일이 미래이므로 `적용 대기`이며 기존 정담당 박지호 유지 확인.
- 로컬 계정을 다른 부서 한도윤으로 전환하면 해당 부서 업무만 표시됨. 전체 데모 계정 메뉴를 통해 김민서로 복귀 확인.
- 동일 출처 POST가 거절되던 localhost/127.0.0.1 차이를 수정하고, 실제 브라우저 저장·수락 성공으로 재검증.
- 데스크톱 대시보드·업무 상세 화면의 배치 확인.
- 폭 390px 모바일 화면에서 메뉴·일정·카드 확인. 문서 폭과 본문 폭 모두 375px(스크롤바 제외)로 수평 넘침 없음. 단위업무 카드는 한 열로 배치.
- 화면 크기 검증 후 브라우저 뷰포트를 기본값으로 복원.

대시보드 캡처는 `artifacts/dashboard.jpg`에 보관했다. API 통합 검증의 별도 가상 업무와 인계는 [API-SMOKE.md](API-SMOKE.md)에 기록되어 있으며 폐기·취소 이력을 유지한다. 이 문서의 브라우저 확인은 실제 변경을 포함하므로 초기 예제와 현재 저장된 상태가 일부 다르다.

## 검증 범위

외부 계정과 키를 제공받지 않아 Neon 실계정·Vercel 배포·실제 사용자 로그인·파일 저장소·AI·법령 API는 종단 검증하지 않았다. 조직개편 일괄 이관, 비동기 작업, 필드별 수정 허용, 휴일 정책 등 미구현 항목은 [ACCEPTANCE.md](ACCEPTANCE.md)에 구분했다.
