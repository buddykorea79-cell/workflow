# 집행 날짜와 부서 예산 집계 검증

기준일: 2026-11-06.

## 구현 범위

- 집행 입력에서 시각을 제거하고 집행일·사업명·사업자·금액·비고를 입력합니다. 기존 시각은 호환을 위해 보존하며 신규 기록에는 생성하지 않습니다.
- 부서담당자·부서장은 자기 부서, 관리자는 선택 부서의 예산을 조회합니다. 다른 역할 또는 다른 부서 접근은 API에서 차단합니다.
- 회계연도별로 원장 단위사업 → 세부사업을 묶습니다. 동일 세부사업 원장은 한 번만 합산하고 연결된 업무의 해당 연도 집행액을 합산합니다.
- 현재 원장 금액을 사용하며 원장에 없는 항목만 최신 업무 연결 사본을 사용합니다. 이 조회는 업무 예산을 변경하지 않습니다.
- 직접 입력 예산·비예산·다른 회계연도 예산에 연결된 집행은 별도 집계합니다. 보관 업무는 포함하고 삭제된 업무·단위업무 및 미등록 공통업무는 제외합니다.
- 검색 결과, 단위사업 소계와 전체 합계를 CSV로 내려받습니다. CSV의 문자열 수식 시작 문자와 따옴표를 처리합니다.

## 검증

| --- | --- |
| 전체 자동 테스트 | 402개 통과, 실패 0개 |
| TypeScript / Next.js 배포 빌드 | 통과 |
| 예산 집계 도메인·API | 중복 예산, 다른 부서·역할 접근, 비활성 계정, 회계연도, 원장 변경·사본, 보관·삭제, 합계 범위, 원본 보존 검증 |
| 날짜 전용 집행 | 시각 없는 신규 기록 저장, 날짜 검증, 기존 시각 유무 혼합 기록 호환, 실제 컴포넌트 렌더 검증 |
| 격리 서버 HTTP | 비로그인 401, 일반 직원 403, 다른 부서 403, 자기 부서 조회 200, 관리자 부서 선택 200 |
| 브라우저 집계 | 예산 20,608,000,000원을 연결한 업무 2개 → 예산 1회, 집행 5,000,000원, 잔액 20,603,000,000원 확인 |
| 브라우저 집행 입력 | 집행일·사업명·사업자·금액·비고 표시, 시각 입력 없음 |
| CSV | 내려받은 파일의 예산·집행·잔액 및 소계·합계가 화면과 일치 |

격리 검증 자료는 `.qa-data/department-budget-preview`에 생성했습니다. 기존 로컬 업무나 Neon 업무에 시험 기록을 추가하지 않았습니다. 상세 로그와 화면은 `.qa/department-budget-full-tests.log`, `.qa/department-budget-build.log`, `.qa/department-budget-summary.png`에 있습니다.

집계의 확정 예산은 연결된 원장의 사업 전체 금액입니다. 부서 배정 한도가 아니며, 다른 부서의 집행액을 포함한 기관 전체 잔액으로 해석하지 않습니다.
