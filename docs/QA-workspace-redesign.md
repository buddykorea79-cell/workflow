# 업무 화면 가독성 및 역할별 메뉴 개선

검증일: 2026-11-05. 프로토타입의 기존 데이터와 수행 기능을 유지하면서 화면과 담당 관계 조회를 개선했습니다.

## 화면 변경

- 흰 작업 영역과 옅은 배경을 구분하고 본문·보조 글자의 대비를 높였습니다. 작은 글씨는 주로 14px 이상, 본문은 15~16px로 정리했습니다.
- 버튼·입력칸·탭·표·팝업의 경계, 선택 상태, 모서리와 여백을 통일했습니다. 업무 홈, 공통업무, 상세, 인수인계, 성과·평가와 사용 안내에도 적용됩니다.
- 개인업무의 전체 업무는 단위업무 → 세부업무 트리입니다. 단위별 접기·펼치기와 전체 접기·펼치기, 단위·세부 이름 검색, 개인/공통 필터를 제공합니다.
- 세부업무 행에 제목, 종류, 담당자, 마감, 절차와 진행 상태를 모았습니다. 기존 보기·수정·삭제·복원과 공통업무 등록 기능을 유지했습니다.
- 공통업무 등록 대기는 접었다 펼치는 영역으로 정리했습니다. 첫 화면에서 작업 목록에 빨리 접근할 수 있도록 안내 영역과 단위 헤더를 줄였습니다.

## 역할별 메뉴

| 메뉴 | 대상 | 기능 |
| --- | --- | --- |
| 개인업무 | 업무 담당자·팀장·부서담당자·관리자 | 본인 단위·세부업무 트리와 수행 기록 |
| 업무분장표 | 전체 구성원 | 같은 부서의 단위·세부업무, 담당·지원, 주기, 기준 상태 확인 |
| 업무분장표 상세 | 부서장·관리자 | 기존 상세 검토, 부서 전체 확정·재작성 허용 유지 |
| 배부·승인 관리 | 부서담당자·관리자 | 받은 공통업무의 팀 배부, 공통업무 승인 요청 현황, 인수인계 대기 |
| 공통업무 · 지시사항 | 기존 역할별 메뉴 유지 | 작성·승인 요청, 부서장 승인·반려, 대상 부서 배부 및 진행 확인 |

부서담당자는 업무를 배부하고 승인 결과를 확인합니다. 공통업무 배포와 인수인계의 최종 승인 권한은 해당 부서장에게 유지됩니다. 부서 업무분장이 확정되어 있다면 기존과 같이 재작성 허용 후 배부할 수 있습니다.

## 분장표 조회 범위

`Workspace.departmentDivision`은 자기 부서의 제목·담당 관계·반복 주기·기준 상태만 담는 조회용 자료입니다. 다른 사람의 근거·첨부·업무 설명·실적·절차·회차·변경 이력은 이 자료에 포함하지 않습니다. 기존 상세 열람 권한이 있는 업무만 제목을 눌러 열 수 있습니다.

삭제·보관된 업무와 등록 전 공통업무는 제외합니다. 표의 기준 상태는 업무분장 작성·확정 상태이며 실행 완료와 다릅니다. 재작성 중 과거 확정 날짜는 ‘마지막 확정’으로 표시합니다.

## 실제 검증

- 자동 테스트 **283개 통과**: 공통업무 승인, 기존 배정·인수인계·수행 회귀, 부서 경계와 최소 분장 데이터 검증 포함.
- HTTP 공통업무 현황 13개, 예산 시연 9개, 지시사항 13개, 전체 업무 흐름 26개 검증 통과(총 61개).
- 브라우저: 송주무관의 공통업무 작성 → 최과장 승인 → 기획재정담당관실 김담당의 새 메뉴에서 팀 배부 → 이팀장의 정주무관 배정 → 기록·자료 관리 단위에 등록 완료.
- 브라우저: 전체 접기 시 세부 행 숨김, 한 단위 펼치기, 검색 시 해당 업무만 표시, 세부 보기와 단위 선택 동작 확인.
- 일반 업무 담당자의 분장표에서 동료 업무 요약이 표시되며, 승인 버튼과 권한 없는 업무의 상세 링크는 없는 것을 확인.
- 데스크톱 1280px 및 모바일 390px에서 개인업무·업무분장표의 페이지 가로 넘침 없음. 390px 세부업무 팝업에서 탭 스크롤과 내용을 확인.
- 화면 증거: `.qa/redesign-personal-tree.png`, `.qa/redesign-division.png`, `.qa/redesign-allocation.png`.

격리 환경: `http://127.0.0.1:3001`, `.qa-data/common-publication-preview`. 실제 Neon DB를 초기화하거나 테스트 업무를 추가하지 않았습니다. 기존 DB에 새 스키마 초기화나 환경변수 추가는 필요하지 않습니다.

최종 빌드: `npm run build` 통과(Next.js 16.4.3, TypeScript 검사 및 10개 페이지 생성 완료). 로그 `.qa/redesign-build.log`.
