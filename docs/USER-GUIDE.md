# 온이음 사용 안내

## 화면별 도움말

개인업무의 제목 아래에는 **단위업무는 업무 묶음, 세부업무는 실제 수행할 과제입니다.**를 표시합니다. 제목 옆 **도움말**을 누르면 업무 만들기, 두 AI 기능의 차이, 절차·일정·성과와 수정 권한 안내가 열립니다. 닫기나 Escape로 닫으면 도움말 버튼으로 돌아옵니다.

공통업무·인수인계·성과평가의 설명은 **접기/자세히**, **다시 보지 않기**로 정리할 수 있습니다. 상태는 이 브라우저에서 사용자별로 기억합니다. 제목 옆 **도움말**을 누르면 같은 화면의 안내를 다시 펼치며, 다른 보기나 조회 조건에 있는 안내도 다음에 표시될 때 복원됩니다. 이후 개별 안내를 다시 숨기면 그 선택을 유지합니다. 진행률 산식 등 필수 범례는 요약을 계속 표시합니다.

## 업무분장표

화면 상단 검색 옆의 **업무분장표**를 누릅니다. 주변 메뉴와 같은 간단한 아이콘·글자 형태이며 별도 박스 없이 표시됩니다. 업무 담당자·팀장·부서 담당자·부서장은 **소속 부서만** 봅니다. 같은 부서 구성원은 역할에 관계없이 동일한 분장표를 봅니다. **관리자만 전 부서**를 조회하고 부서를 선택할 수 있습니다.

표는 **담당자 → 단위업무 → 세부업무 → 업무대행자** 순서입니다. 업무 코드는 표시하지 않습니다. 팀·담당자 이름으로 조회 조건을 좁힐 수 있으며 관리자에게는 부서 필터도 제공됩니다.

**Excel 다운로드**는 실제 `.xlsx`, **PDF 다운로드**는 한글 글꼴을 포함한 PDF 파일을 내려받습니다. 현재 조회 조건과 로그인한 사람의 부서 범위를 적용하며, 업무대행자는 승인되어 현재 대행 기간 안에 있는 사람만 표시합니다. 자세한 기준과 다운로드 구현은 [업무분장표·다운로드 안내](./ORGANIZATION-DIVISION-EXPORT.md)에 있습니다.

분장표에는 업무 제목과 담당 관계만 표시합니다. 업무 설명·절차·예산·성과·파일 본문의 접근 권한은 별도로 적용합니다. 부서장·관리자의 상세 조회와 확정·재작성은 **부서 업무 관리**에서 진행합니다.

## 역할별 주요 메뉴

| 역할 | 주로 하는 일 |
| --- | --- |
| 업무 담당자 | 개인업무 작성·수행, 공통 세부업무 작성과 배포 승인 요청, 업무대행 요청·수행, 성과 제출 |
| 팀장 | 부서 담당자가 배정한 공통업무의 수행 담당자 지정, 본인 업무와 지정 검토 수행 |
| 부서 담당자 | 배정·승인 관리에서 받은 공통업무를 팀에 배정, 부서원 업무대행 요청, 인수인계 보관·재배정 요청과 승인 현황 확인 |
| 부서장 | 공통업무 배포·업무대행·인수인계 승인 및 반려, 부서 업무분장 확정·재작성 허용, 성과 평가 |
| 관리자 | 조직·구성원 관리, 전 부서 업무분장 조회, 업무 관리와 배정 지원, AI·DB·파일 연결 테스트, 변경 기록 확인. 부서장 전용 승인을 대신하지 않음 |

공통업무 전용 추가 권한은 없습니다. 일반 업무 담당자가 작성한 공통 세부업무는 **작성 부서장 승인 → 대상 부서 접수 → 부서 담당자의 팀 배정 → 팀장의 담당자 배정 → 담당자의 개인업무 등록** 순서로 이어집니다. 추가 대상 부서도 다시 승인을 받습니다.

왼쪽 메뉴의 관련 업무 순서는 **업무대행 → 인수인계 → 성과 · 평가**입니다. 처음 화면의 **온이음 사용 안내**와 로그인 후 같은 이름의 메뉴에서 역할별 상세 설명을 볼 수 있습니다.

## 단위업무 중요도와 성과평가 비중

**단위업무 추가** 또는 **단위 수정**에서 중요도를 1~10의 정수로 입력합니다. 숫자가 클수록 중요하며, 새 단위업무와 기존 단위업무의 기본값은 5입니다. 개인업무의 단위업무는 중요도가 높은 순서로 표시하고, 중요도가 같으면 기존 순서를 유지합니다.

**성과 · 평가 → 업무 비중 설정**을 처음 열면 중요도 비율에 따라 합계 50점을 정수로 제안합니다. 예를 들어 중요도가 10·5·5이면 25·13·12점으로 배분합니다. 비율 계산으로 1점 미만이 되는 항목은 1점으로 고정하고 나머지 배점을 다시 계산합니다. 나누어떨어지지 않는 점수는 소수 부분이 큰 순서로 1점씩 더하고, 소수 부분까지 같으면 기존 단위업무 순서를 따릅니다.

비중은 직접 수정할 수 있으며, 각 항목은 **최소 1점인 1~50의 정수**이고 합계는 50점이어야 합니다. 단위업무가 50개이면 각각 1점이며, 50개를 초과하면 비중을 배분·저장할 수 없습니다. **중요도 기준으로 다시 배분**을 누르면 확인 후 현재 입력값을 새 제안으로 바꿀 수 있습니다. **업무 비중 저장**을 눌러야 실제로 반영됩니다.

중요도를 바꾸더라도 저장한 비중이나 확정된 평가 결과를 자동으로 변경하지 않습니다. 기존 0점·소수 비중도 보존하지만, 비중을 새로 저장할 때에는 1점 이상의 정수로 조정해야 합니다. 제출·평가가 완료된 기록의 수정 제한은 기존과 같습니다.

## 개인업무의 세부업무 등록 흐름

세부업무 팝업의 탭은 **업무 개요 → 관련 근거 → 절차 → 일정·수행 → 성과 → 예산·집행** 순서입니다. 지시사항에는 마지막에 **월별 실적**이 추가됩니다.

1. **업무 개요**에서 업무 내용과 담당자를 확인합니다.
2. **관련 근거**에서 참고할 법령·지침·생산 문서를 확인하거나 등록합니다. AI 절차 작성 시 필요한 근거를 선택해 참고할 수 있습니다.
3. **절차**에서 **누가·무엇을·어떻게**를 중심으로 할 일을 나누고, 절차별 **참고 파일 → 파일 추가**로 필요한 자료를 연결합니다. 파일은 절차마다 최대 30개, 파일당 10MB입니다. 수기로 절차를 추가하고 **위로·아래로**로 순서를 조정할 수 있습니다. 업로드·수정 후 주황색 **수정사항 저장·절차도 반영** 또는 **저장하고 일정 등록**을 눌러 연결을 반영합니다.
4. **일정·수행 → 일정 등록**에서 만들어 저장한 절차의 시작일 또는 종료일을 정합니다. 전체 기간은 입력한 절차 날짜에서 자동으로 계산되며 회차 이름을 따로 입력하지 않습니다. 날짜를 비워 둔 절차는 **일정 미정**으로 표시되고, 준비 사항·장소는 **진행 방법 · 일정 메모**를 펼쳐 적습니다.
5. **성과**에서 연도·반기를 선택하고 결과와 개선점을 **500자 이내**로 작성합니다. 글자 수를 확인하면서 내용을 정리하고 필요한 **성과 참고 파일**을 첨부한 뒤 **성과 저장**을 누릅니다. 파일은 성과별 최대 30개, 파일당 10MB입니다. 제목·근거 설명·지표는 별도로 입력하지 않습니다.

저장한 성과는 **성과 · 평가**에서 단위업무별로 확인하고 업무 비중을 설정한 뒤 제출합니다. 기존 성과에 입력했던 지표와 근거 설명은 보존되며, 이전 근거는 접힌 항목에서 볼 수 있습니다. 절차·성과 파일의 다운로드 가능 여부는 파일 옆에 표시됩니다.

작성 중인 내용이 사라지는 탭·반기 이동이나 창 닫기에는 **계속 작성 / 저장하지 않고 이동** 안내가 표시됩니다. 계속 작성을 선택하면 입력을 유지하며, 실제 저장은 각 화면의 저장 버튼으로 진행합니다. 업무 개요·절차처럼 같은 창 안에서 유지되는 수정 내용은 탭을 오가며 함께 작성할 수 있습니다. 변경사항이 없으면 업무 저장 버튼은 비활성화됩니다.

일정은 미정인 절차를 사이에 두더라도 앞선 절차보다 먼저 시작할 수 없습니다. **일정·수행 → 회차 메모**에는 진행 상황이나 정정 내용을 남길 수 있으며, 완료 후에도 원래 결과를 바꾸지 않고 보완 메모를 추가합니다.

인수인계 전 작성한 성과는 **성과 · 평가**에서 내용과 참고 파일을 보완할 수 있습니다. 파일은 그 성과에만 연결되며 후임자의 업무 권한으로 열람되지 않습니다. 이미 제출·평가한 성과는 편집할 수 없고, 평가 전 제출 회수 후 보완합니다.

## 업무 담당자 1·2 시연

| 로그인 선택 | 기본 계정·부서 | 시연 역할 |
| --- | --- | --- |
| 업무 담당자 1 | 송주무관 · 데이터정보화담당관실 | 공통업무 작성·배포 요청 |
| 업무 담당자 2 | 임주무관 · 혁신행정담당관실 | 공통업무를 배정받아 수행 |

두 선택 항목은 시연 계정을 빠르게 고르는 기능이며 실제 조직 권한은 모두 **업무 담당자**입니다. 로그인 화면이나 역할 전환에서 부서와 계정을 확인한 뒤 이동합니다.

담당자 1의 개인업무에는 **통계 간행물 발간 → 행정안전 통계연보 발간**이 준비되어 있습니다. 같은 제목의 공통업무는 혁신행정담당관실을 대상으로 **작성 부서장 승인 대기** 중입니다. 담당자 2에게 미리 승인·배정된 상태는 아닙니다.

1. 담당자 1로 개인업무와 공통업무의 내용·대상 부서를 확인합니다.
2. 데이터정보화담당관실 **부서장**으로 전환해 공통업무 배포를 승인합니다.
3. 혁신행정담당관실 **부서 담당자**로 전환해 접수된 업무를 팀장에게 배정합니다.
4. 배정받은 **팀장**으로 전환해 임주무관을 업무 담당자로 지정합니다.
5. **업무 담당자 2**로 전환해 공통업무를 본인의 **통계 간행물 발간** 단위업무에 등록합니다.

업무분장이 확정되어 배정이 잠겼으면 대상 부서장이 **부서 업무 관리 → 재작성 허용**으로 먼저 열어야 합니다. 상세 계정·단계와 데이터 보존 기준은 [통계연보 시연 안내](./DEMO-STATISTICS-YEARBOOK.md)를 참고하세요.

## 파일로 업무 설명 초안 만들기

1. 개인업무의 세부업무 작성·편집 화면에서 업무 설명용 파일을 먼저 업로드합니다.
2. Kordoc이 읽은 본문을 확인합니다. 누락·읽기 오류가 있으면 본문을 보완하거나 파일을 다시 선택합니다.
3. 확인한 본문으로 BizRouter AI 설명 초안을 만듭니다.
4. 초안을 원문과 비교하고 필요한 내용을 수동으로 적용합니다.
5. 업무를 저장해 설명을 반영합니다.

업로드, AI 초안 생성, 설명 적용, 업무 저장은 서로 다른 단계입니다. AI 결과를 확인하기 전에 기존 설명을 자동으로 덮어쓰지 않습니다. 저장한 업무 설명과 업무 개요의 첨부파일은 **절차** 탭의 AI 분석에서도 우선 자료로 사용합니다.

## 법령·행정규칙에서 조문 가져오기

1. **세부업무 → 업무 기준 수정 → 관련 근거 → 법령·행정규칙 검색**을 엽니다.
2. 자료 종류를 **법령 / 행정규칙**, 검색 범위를 **제목 / 본문**으로 선택하고 키워드를 검색합니다.
3. 검색 결과의 시행일·소관기관을 확인하고 **조문 보기**를 누릅니다. 조문 번호·제목·본문의 키워드로 필요한 조문을 좁힐 수 있습니다.
4. **조문 본문 보기**에서 항·호·목까지 확인하고 필요한 조문을 선택한 뒤 **근거에 추가**합니다. 행정규칙에 조문 번호가 없으면 제공되는 본문 단위로 선택합니다.
5. 추가된 제목·내용·원문 링크를 검토하고 **변경사항 저장**을 누릅니다. 기존 근거·첨부파일은 유지되며, 같은 내용은 중복으로 추가하지 않습니다.

조회한 원문은 가져온 시점의 본문으로 보관됩니다. 이후 개정 내용으로 자동 갱신되지 않으므로 적용 시점과 원문을 확인하세요. 별표·서식은 화면의 안내에 따라 공식 원문에서 확인합니다. 연결 설정은 [법령 API 설정 안내](LAW-API-SETUP.md)를 참고하세요.

## 업무 개요와 첨부파일로 AI 요약·절차 만들기

1. 세부업무의 **업무 개요**에서 업무명·업무 설명·완료 기준을 확인하고 업무 설명용 파일을 연결한 뒤 저장합니다. AI는 이 개요와 첨부파일을 먼저 읽어 수행 범위와 흐름을 정합니다.
2. 참고할 법령·지침·생산 문서가 있으면 **관련 근거**에 내용이나 파일을 등록하고 저장합니다. 관련 근거는 절차의 조건·의무·누락·충돌을 검토하는 보완 자료입니다. 관련 근거가 없어도 충분한 업무 설명이나 첨부파일이 있으면 절차를 만들 수 있습니다.
3. **절차** 탭 상단의 **AI로 절차·절차도 작성**을 엽니다. 업무 기준 수정 권한이 있으면 보기 모드에서도 바로 시작할 수 있습니다. 업무 개요와 여기에 연결한 첨부파일은 자동으로 포함되며, 관련 근거는 필요한 항목을 선택합니다. HWP·HWPX·PDF·DOCX·XLSX·XLS·PPTX는 Kordoc으로, TXT·CSV는 텍스트로 읽습니다. AI 분석을 실행하면 자료별 요약, 전체 요약과 절차 초안이 생성됩니다.
4. 개요·첨부파일에 적힌 업무 내용이 반영되었는지 확인하고 관련 근거와의 충돌·누락 경고, 원문 인용, 역할·순서·완료 조건을 검토합니다. 초안을 확인했다는 항목을 선택한 뒤 주황색 **초안 저장·절차도 반영**을 누르면 새 절차가 **즉시 저장되어 현재 절차 전체를 교체**하고 분석 창이 닫힙니다. 별도의 변경사항 저장은 필요하지 않습니다.

업무 개요를 우선한다는 것은 적용 법령이나 필수 조건을 무시한다는 뜻이 아닙니다. 자료가 서로 충돌하면 경고와 원문을 확인하고 초안을 보완하세요. 업무 개요·첨부파일·선택한 관련 근거를 합친 분석 본문은 60,000자까지 지원합니다. 개요 첨부파일은 최대 10개, 보완할 관련 근거는 최대 20개입니다.

개인업무 상단의 **AI 업무등록**은 새 단위업무·세부업무의 초안을 만드는 기능입니다. 위의 **AI로 절차·절차도 작성**은 이미 등록된 세부업무 안에서 수행 단계와 절차도를 만드는 별도 기능입니다.

파일은 10MB 이하, 문서는 150쪽 또는 섹션 이하, 추출 본문은 20만 자 이하로 준비합니다. 분석 범위와 길이 제한은 화면 안내를 확인합니다. 자동 OCR은 사용하지 않으므로 스캔·이미지 문서는 OCR 처리한 문서로 올리거나 본문을 직접 보완합니다. 파일을 교체하면 새 파일에서 읽은 본문과 기존 본문이 일치하는지 확인하세요.

## 수기로 절차 추가·순서 조정·한 번에 반영

AI 초안의 **초안 저장·절차도 반영**은 기존 절차 뒤에 단계를 덧붙이지 않고 현재 절차를 새 목록으로 교체합니다. 적용 후에는 현재 절차도 하나만 표시됩니다.

새 수기·AI·규칙 초안은 누가·무엇을·어떻게와 참고 파일을 중심으로 작성합니다. 지원자가 없으면 담당자를 기본으로 사용하고 미지정 지원 역할은 새로 선택할 수 없습니다. 새 초안에는 별도의 필수 결과물·체크리스트를 만들지 않으며 필요한 안내를 수행 방법에 표시합니다. 이전에 저장한 절차와 과거 수행 이력은 유지됩니다.

1. 세부업무에서 **업무 기준 수정 → 절차**를 엽니다.
2. **수기로 절차 추가**를 누르고 **누가·무엇을·어떻게**와 참고 파일을 입력합니다. 먼저 완료할 절차·결과물·확인 항목 등을 따로 입력하지 않습니다. 불필요한 미완료 절차는 삭제할 수 있습니다.
3. 각 절차의 **위로·아래로** 버튼으로 순서를 조정합니다. 조정한 목록 순서대로 흐름이 연결됩니다. 완료된 절차까지의 순서는 보존됩니다.
4. 주황색 **수정사항 저장·절차도 반영**을 누릅니다. 작성한 내용과 순서를 함께 저장하고 상단 절차도에 반영합니다. AI 작성 영역과 절차도는 상단에 표시되며 본문과 함께 스크롤되어 아래 절차를 가리지 않습니다. 확대 보기에서는 전체 흐름을 넓게 확인할 수 있습니다.

| 동작 | 결과 |
| --- | --- |
| 초안 저장·절차도 반영 | AI 초안으로 전체 교체하고 저장·절차도 반영 |
| 수기로 절차 추가 / 위로·아래로 | 새 절차 작성 / 목록 순서 조정 |
| 수정사항 저장·절차도 반영 | 현재 절차의 내용·파일·순서를 한 번에 저장하고 절차도 반영 |

절차도와 단계 목록에는 **담당자 수행·협업 지원·검토 승인** 역할과 배정된 사람의 이름을 함께 표시합니다. 일정·수행은 해당 회차의 배정자를, 지난 회차와 교체 이력은 당시 저장한 배정자를 기준으로 표시합니다. 업무대행자가 실제로 수행했다면 완료자에는 대행자의 이름이 별도로 남습니다. 주체 표시가 업무 기준 수정이나 승인 권한을 추가하지는 않습니다.

진행 중 회차에서 AI 절차를 교체하면 이전 절차·수행 상태·결과·체크리스트·메모를 보관하고 새 절차를 미완료 상태로 시작합니다. **일정·수행 → 이 회차의 절차 변경 이력**을 펼친 뒤 교체 시점을 선택하면 교체 시각·교체자·사유·이전 절차와 수행 결과를 확인할 수 있습니다. 이력은 기본적으로 접혀 있으며 현재 절차와 섞어 표시하지 않습니다.

**이미 완료된 회차는 바뀌지 않습니다.** 완료 회차의 절차·일정·당시 배정·완료자·결과는 **지난 회차**에서 확인합니다. 완료 후 바꾼 업무 기준은 다음 회차를 시작할 때 적용됩니다. 업무분장이 확정되어 있으면 부서장의 재작성 허용을 먼저 받고, 공통업무의 필수 절차와 검토 단계 등 기존 기준을 지켜야 합니다.

## 확정 예산 검색과 집행잔액

관리자의 **예산 관리**에는 제공된 `2026년 예산 개요.pdf`의 세출예산 상세표가 등록됩니다. 원문 PDF 15~25쪽의 **2026년 확정(b)** 열을 사용하며 백만원을 원 단위로 변환했습니다. 회계·분야·부문·프로그램·단위사업·세부사업·출처 페이지를 함께 보관합니다. 원문 총계와 상세 항목 합계 검증, 요약표와 상세표의 항목 수 차이는 [추출 검증 안내](BUDGET-2026-SOURCE.md)에 기록했습니다.

1. 세부업무 등록 화면 또는 **업무 기준 수정 → 예산·집행**에서 **확정 예산 검색**을 누릅니다.
2. 사업명이나 분야·부문·프로그램 키워드를 입력합니다. 회계와 계층, 출처 페이지, **2026년도 확정 예산**을 확인하고 **예산에 적용**을 누릅니다.
3. 업무를 저장하면 선택한 항목과 확정액을 연결합니다. 이 값은 선택한 세부사업의 전체 확정액이며, 여러 업무에 나누어 배정한 금액을 뜻하지 않습니다. 별도의 업무 금액을 관리하려면 직접 입력으로 변경합니다.
4. 예산이 없는 업무는 **비예산 사업**을 선택합니다. 확정액이 0원인 원장 항목과 비예산 표시는 별개입니다. 기존 집행금액이 있는 업무는 기록을 유지한 채 비예산으로 바꿀 수 없습니다.
5. **집행 추가**에서 집행일, 사업명, 사업자, 금액, 내용·비고를 입력합니다. 집행시간은 입력하지 않습니다. 업무분장이 확정된 이후에도 기존 권한에 따라 **수행 기록 입력 → 예산·집행 → 수행 기록 저장**으로 집행내역을 기록합니다.

연결 예산의 잔액은 **해당 회계연도 확정 예산 - 이 세부업무의 같은 연도 집행 합계**입니다. 다른 연도 기록은 보존하며 계산에서 제외한다고 표시합니다. 직접 입력 예산은 등록된 전체 집행 금액을 차감합니다. 같은 예산을 연결한 다른 세부업무의 집행액을 합산한 사업 전체 잔액은 아닙니다. 예산을 초과하면 음수 잔액과 초과 안내를 표시합니다.

기존 집행기록에 없던 사업명·사업자는 필요할 때 보완할 수 있습니다. 기존에 저장한 시각은 호환을 위해 보존하지만 화면에는 표시하지 않습니다. 관리자가 원장을 수정해도 이미 업무에 연결한 예산은 자동 변경되지 않습니다. 최신 금액을 반영하려면 업무에서 해당 예산을 다시 검색·선택하고 저장합니다.

### 부서 예산 집계

부서담당자와 부서장은 왼쪽 **부서 예산 집계**에서 소속 부서의 예산·집행액을 일괄 조회합니다. 관리자는 부서를 선택할 수 있습니다. 일반 업무 담당자·팀장에게 부서 전체 예산 조회 권한을 부여하지 않습니다.

- 회계연도를 선택하면 예산 원장의 **단위사업 → 세부사업** 순서로 연결 확정 예산, 부서 집행액, 차감잔액과 연결 업무 수를 표시합니다. 단위사업별 소계와 전체 합계를 함께 확인합니다.
- 같은 세부사업 예산이 여러 업무에 연결되어도 확정 예산은 **한 번만** 합산합니다. 집행액은 그 예산을 연결한 소속 부서 업무의 선택 연도 집행 기록을 모두 합산합니다. 회계·분야·부문·프로그램이 다르면 이름이 같아도 별도 단위사업으로 구분합니다.
- 집계의 연결 확정 예산은 **현재 원장 금액**이며, 부서에 별도로 배정한 한도가 아닙니다. 원장에 없는 항목만 업무에 보존된 연결 정보를 사용합니다. 업무별 연결 당시 금액과 현재 원장 금액이 다르면 표시합니다. 이 조회는 업무에 저장된 예산을 변경하지 않습니다.
- 직접 입력한 예산은 회계연도가 지정되지 않아 별도 요약으로 보여주며, 집행액만 선택 연도로 제한합니다. 비예산 업무 수와 연결 예산의 연도와 다른 집행액도 따로 확인합니다.
- 보관 상태 업무는 포함하며, 삭제된 업무·단위업무와 미등록 공통업무는 제외합니다. 다른 부서의 집행내역은 포함하지 않습니다.

### 관리자 예산 원장

- **관리자 → 예산 관리**에서 항목을 검색하고 추가·수정합니다. 사용하지 않을 항목은 **검색 제외**로 전환하고 필요하면 다시 포함할 수 있습니다.
- **JSON 다운로드**는 현재 관리 중인 원장을 내보냅니다. **JSON 가져오기**는 같은 ID를 갱신하고 새로운 ID를 추가하며, 파일에 없는 기존 항목은 유지합니다. 미리보기를 확인한 뒤 가져오기를 실행합니다.
- 초기 원장은 배포된 JSON에서 제공됩니다. 관리자의 변경은 기존 저장소 설정에 따라 Neon DB 또는 로컬 저장소에 보관되고 변경 기록이 남습니다. 현재 업무의 예산 연결과 집행 기록은 유지됩니다.

## 업무대행

일시적인 부재에는 업무대행을 이용합니다. 인사이동으로 담당자를 영구히 바꾸는 **인수인계**와 구분합니다.

1. 원담당자 또는 부서 담당자가 **업무대행 → 업무대행 요청**을 엽니다. 부서 담당자는 먼저 원담당자 한 명을 선택합니다.
2. **담당자 → 단위업무 → 세부업무 → 현재 업무대행자** 형태의 표에서 체크박스를 선택합니다. **전체 업무 선택**, 단위업무 단위 선택, 세부업무 일부 선택을 조합할 수 있습니다. 요청 시 선택한 업무만 포함되며 이후 새로 만든 업무는 자동 추가되지 않습니다.
3. 조직도에서 같은 부서 대행자를 선택하고 시작일·종료일·사유를 입력합니다. 종료일은 해당 날짜 전체를 포함합니다. 선택 업무는 한 요청으로 묶이며 한 번에 최대 300건까지 요청할 수 있습니다. 다른 원담당자는 별도로 요청합니다.
4. 원 업무가 속한 부서의 부서장이 **요청 상세**에서 선택 업무 전체를 확인하고 함께 승인하거나 사유를 남겨 반려합니다. 요청 후 담당자·업무 기준·기간이 달라진 업무가 하나라도 있으면 전체 승인이 중단되므로 최신 내용으로 다시 요청합니다.
5. 승인된 대행 기간이 시작되면 대행자의 **개인업무 → 업무대행** 묶음에서 원본 업무를 엽니다.
6. 허용된 수행 기록을 입력합니다. 원담당자와 대행자는 같은 원본과 기록을 사용합니다.
7. 기간이 끝나거나 대행이 종료되면 대행 권한과 현재 대행 목록에서 제외됩니다. 이미 작성한 기록은 남습니다.

업무대행 묶음은 화면에서 대행 업무를 모아 보여주는 가상 단위입니다. 원본 업무·단위업무를 복제하거나 소유자를 바꾸지 않습니다. 업무 기준 편집, 최종 검토와 부서장 승인 권한은 대행자에게 넘어가지 않습니다.

세부업무 등록·편집 화면의 업무대행 지정에서도 요청할 수 있습니다. 이미 등록된 세부업무의 대행 승인 요청에서는 같은 원담당자의 다른 단위·세부업무도 함께 선택할 수 있습니다. 같은 업무의 대행 기간이 겹치거나 선택 업무의 검토자를 대행자로 지정하면 요청할 수 없습니다.

## 배정·승인 관리와 인수인계

부서 담당자는 **배정·승인 관리**에서 받은 공통업무를 팀에 배정하고, 공통업무 승인 요청과 인수인계 대기·처리 현황을 확인합니다. 업무분장이 확정되어 배정가 잠겼다면 부서장이 **부서 업무 관리**에서 재작성을 허용한 뒤 처리합니다.

갑작스러운 인사이동은 **인수인계**에서 기존 업무를 부서 담당자에게 우선 보관합니다. 새 담당자가 정해지면 전체 또는 일부 업무를 선택해 부서장 승인 후 재배정합니다. 단위·세부업무의 소유권 이전과 지원·검토·총괄 등 남은 역할 정리는 각각의 요청 범위를 확인해 처리합니다.

승인 대기 중인 인수인계 요청은 요청자·해당 부서담당자·관리자가 상세 화면에서 취소할 수 있습니다. 업무대행 승인 알림은 해당 요청 상세로, 반기 성과 평가 알림은 해당 직원과 반기의 평가 화면으로 바로 연결됩니다.

## 관리자 연결·테스트

관리자 계정으로 **관리자 → 연결·테스트**를 엽니다. 연결값이 있다는 표시와 실제 시험 성공은 다르므로 원하는 시험을 직접 실행합니다. 각 결과에는 단계별 성공 여부·메시지·확인 시각·소요 시간이 표시됩니다.

| 버튼 | 확인하는 내용 |
| --- | --- |
| 설정 새로고침 | 환경변수의 현재 설정 여부. 키·비밀번호의 실제 값은 표시하지 않음 |
| AI 연결·응답 테스트 | BizRouter 모델 접근 권한과 짧은 고정 시험 문장의 응답. 소량의 실제 API 사용량 발생 |
| DB 연결·읽기·쓰기 테스트 | DB 연결과 업무 데이터 조회·쓰기 권한. 시험 쓰기는 트랜잭션 롤백 |
| 파일 저장소 연결 테스트 | 임시 파일 저장·다시 읽기·내용 비교 후 해당 시험 파일 정리 |
| 업로드·다운로드 테스트 | 실제 브라우저 업로드·다운로드, 원본 일치, Neon CORS와 시험 파일 정리 |

브라우저 시험은 1MB 이하 파일을 선택하거나 아무 파일도 선택하지 않고 자동 생성된 작은 텍스트로 진행합니다. 성공 후 **확인한 파일 내려받기**로 로컬 사본을 저장할 수 있습니다. 시험 파일은 일반 업무 첨부로 등록되지 않고 저장소에서 정리됩니다. 정리가 실패하면 **임시 파일 정리 재시도**로 마무리합니다.

연결값은 관리자 화면에서 입력하지 않습니다. 로컬에서는 프로젝트 `.env.local`에 저장한 뒤 서버를 재시작합니다. Vercel에서는 프로젝트 **Settings → Environment Variables**에 저장하고 **Redeploy**한 뒤 설정 새로고침을 누릅니다. Vercel 값이 로컬로 자동 복사되지는 않습니다.

- DB: Neon 프로젝트 **Connect**에서 `DATABASE_URL`을 확인합니다.
- 파일: Neon **Connect → Storage → Parameters only**에서 `AWS_ENDPOINT_URL_S3`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`를 확인합니다. `IEUM_STORAGE_PROVIDER=neon`을 설정하고 기본 버킷은 `ieum-attachments`를 사용합니다. CORS에는 실제 앱 주소, `PUT, GET, HEAD`, `Content-Type`을 허용합니다.
- AI: BizRouter 관리 화면에서 API 키와 사용 가능한 모델 ID를 확인해 `BIZROUTER_API_KEY`, `BIZROUTER_MODEL`을 설정합니다. JSON 구조화 응답을 지원하는 모델을 사용합니다.

화면의 **연결값을 어디에서 확인하고 설정하나요?**를 펼치거나 [Neon 프로토타입 설정 안내](./PROTOTYPE-NEON-SETUP.md)를 참고하세요.

## AI 업무등록

1. 개인업무 상단의 주황색 **AI 업무등록**을 누릅니다.
2. 맡은 업무의 목적·범위·주요 내용을 적습니다. 인수인계 파일이나 참고 파일도 함께 넣을 수 있습니다. 파일은 최대 10개, 각각 10MB까지입니다.
3. 파일에서 읽은 본문을 확인하고 **AI로 업무 초안 만들기**를 누릅니다. 입력한 설명과 문서 본문은 BizRouter로 전송됩니다.
4. 단위업무와 세부업무의 이름·주요내용을 검토합니다. 필요한 항목을 직접 추가·삭제하고 마감일을 선택합니다. AI는 마감일을 임의로 채우지 않습니다.
5. **검토한 업무 등록**을 누릅니다. 단위업무 최대 10개, 세부업무 합계 30개를 한 번에 등록합니다. 담당자는 본인, 검토자는 소속 부서의 활성 부서장으로 지정됩니다. 기본 4단계 절차는 등록 후 업무별로 수정할 수 있습니다.

분석 중에도 입력할 수 있으며, 새 결과가 기존 작성 내용을 바로 덮어쓰지 않습니다. 등록 결과를 받지 못했다면 **같은 요청으로 등록 결과 확인**을 사용하세요. 처음 보낸 내용을 다시 확인하므로 이후 추가한 수정은 포함되지 않습니다. 등록 완료 후 남은 수정은 **작성 내용 복사**로 보관하고 생성된 업무에서 반영하세요.

분석 파일은 비공개 임시 첨부로 보관되며 생성된 모든 업무에 자동 첨부되지 않습니다. 스캔 이미지나 암호화된 문서는 OCR 처리본을 사용하거나 내용을 직접 입력해 주세요. 부서 업무분장이 확정되었거나 활성 검토자가 없으면 새 등록을 할 수 없습니다.
