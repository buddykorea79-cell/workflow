# 온이음 사용 안내

## 전 부서 업무분장표

화면 상단 검색 옆 **업무분장표** 버튼을 누릅니다. 업무 담당자·팀장·부서 담당자·부서장·관리자 모두 같은 전 부서 내용을 봅니다.

표는 부서별로 **담당자 → 단위업무 → 세부업무 → 업무대행자** 순서입니다. 업무 코드는 표시하지 않습니다. 부서·팀·담당자 이름으로 조회 조건을 좁힐 수 있습니다.

**Excel 다운로드**는 실제 `.xlsx`, **PDF 다운로드**는 한글 글꼴을 포함한 PDF 파일을 내려받습니다. 현재 조회 조건을 적용하며, 업무대행자는 승인되어 현재 대행 기간 안에 있는 사람만 표시합니다. 자세한 기준과 다운로드 구현은 [전체 업무분장표·다운로드 안내](./ORGANIZATION-DIVISION-EXPORT.md)에 있습니다.

전체 분장표에는 업무 제목과 담당 관계만 표시합니다. 업무 설명·절차·예산·성과·파일 본문을 전체 직원에게 공개하는 기능은 아닙니다. 부서장·관리자의 상세 조회와 확정·재작성은 **부서 업무 관리**에서 진행합니다.

## 역할별 주요 메뉴

| 역할 | 주로 하는 일 |
| --- | --- |
| 업무 담당자 | 개인업무 작성·수행, 공통 세부업무 작성과 배포 승인 요청, 업무대행 요청·수행, 성과 제출 |
| 팀장 | 부서 담당자가 배부한 공통업무의 수행 담당자 지정, 본인 업무와 지정 검토 수행 |
| 부서 담당자 | 배부·승인 관리에서 받은 공통업무를 팀에 배부, 부서원 업무대행 요청, 인수인계 보관·재배정 요청과 승인 현황 확인 |
| 부서장 | 공통업무 배포·업무대행·인수인계 승인 및 반려, 부서 업무분장 확정·재작성 허용, 성과 평가 |
| 관리자 | 조직·구성원 관리, 부서별 업무 관리와 배부 지원, 연결·변경 기록 확인. 부서장 전용 승인을 대신하지 않음 |

공통업무 전용 추가 권한은 없습니다. 일반 업무 담당자가 작성한 공통 세부업무는 **작성 부서장 승인 → 대상 부서 접수 → 부서 담당자의 팀 배부 → 팀장의 담당자 배정 → 담당자의 개인업무 등록** 순서로 이어집니다. 추가 대상 부서도 다시 승인을 받습니다.

## 파일로 업무 설명 초안 만들기

1. 개인업무의 세부업무 작성·편집 화면에서 업무 설명용 파일을 먼저 업로드합니다.
2. Kordoc이 읽은 본문을 확인합니다. 누락·읽기 오류가 있으면 본문을 보완하거나 파일을 다시 선택합니다.
3. 확인한 본문으로 BizRouter AI 설명 초안을 만듭니다.
4. 초안을 원문과 비교하고 필요한 내용을 수동으로 적용합니다.
5. 업무를 저장해 설명을 반영합니다.

업로드, AI 초안 생성, 설명 적용, 업무 저장은 서로 다른 단계입니다. AI 결과를 확인하기 전에 기존 설명을 자동으로 덮어쓰지 않습니다. 업무 설명을 만드는 파일과 법령·지침 등 **관련 근거**를 활용한 절차 분석도 각각의 화면에서 관리합니다.

## 업무대행

일시적인 부재에는 업무대행을 이용합니다. 인사이동으로 담당자를 영구히 바꾸는 **인수인계**와 구분합니다.

1. 원담당자 또는 부서 담당자가 **업무대행** 메뉴에서 원본 업무, 같은 부서의 대행자, 시작·종료 시각과 사유를 정해 요청합니다. 세부업무 등록·편집 화면에서도 대행 요청을 할 수 있습니다.
2. 원 업무가 속한 부서의 부서장이 요청을 승인하거나 사유를 남겨 반려합니다.
3. 승인된 대행 기간이 시작되면 대행자의 **개인업무 → 업무대행** 묶음에서 원본 업무를 엽니다.
4. 허용된 수행 기록을 입력합니다. 원담당자와 대행자는 같은 원본과 기록을 사용합니다.
5. 기간이 끝나거나 대행이 종료되면 대행 권한과 현재 대행 목록에서 제외됩니다. 이미 작성한 기록은 남습니다.

업무대행 묶음은 화면에서 대행 업무를 모아 보여주는 가상 단위입니다. 원본 업무·단위업무를 복제하거나 소유자를 바꾸지 않습니다. 업무 기준 편집, 최종 검토와 부서장 승인 권한은 대행자에게 넘어가지 않습니다.

## 배부·승인 관리와 인수인계

부서 담당자는 **배부·승인 관리**에서 받은 공통업무를 팀에 배부하고, 공통업무 승인 요청과 인수인계 대기·처리 현황을 확인합니다. 업무분장이 확정되어 배부가 잠겼다면 부서장이 **부서 업무 관리**에서 재작성을 허용한 뒤 처리합니다.

갑작스러운 인사이동은 **인수인계**에서 기존 업무를 부서 담당자에게 우선 보관합니다. 새 담당자가 정해지면 전체 또는 일부 업무를 선택해 부서장 승인 후 재배정합니다. 단위·세부업무의 소유권 이전과 지원·검토·총괄 등 남은 역할 정리는 각각의 요청 범위를 확인해 처리합니다.
