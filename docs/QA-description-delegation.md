# 파일 기반 설명 · 업무대행 · 전체 업무분장표 검증

## 반영 기능

- 세부업무 등록·수정의 업무 설명 아래에 설명 자료를 첨부한다. 등록 전 원본도 먼저 저장하며 업무 저장 시 첨부를 해당 업무에 연결한다.
- Kordoc으로 문서 본문을 읽고, 사용자가 확인한 본문을 BizRouter로 보내 설명 초안을 생성한다. 파일별 요약·원문 인용을 확인한 뒤 적용·저장한다.
- 최종검토자 선택 입력은 업무대행 지정으로 교체한다. 절차의 검토 역할은 업무대행과 분리하여 부서장으로 지정한다.
- 원담당자 또는 부서 담당자가 같은 부서의 대행자를 요청하고, 원부서장이 승인한다. 대행자는 유효 기간에 개인업무의 **업무대행** 묶음에서 원본 업무를 수행한다.
- 승인·반려·취소·종료, 요청 사유와 실제 수행자를 기록한다. 원본 소유권과 기존 기록은 유지한다.
- 검색 옆 **업무분장표**에서 모든 역할이 동일한 전체 부서 분장표를 조회하고 Excel·PDF로 내려받는다.

## 설치·설정

`kordoc`, `exceljs`, `pdfkit`는 프로젝트 의존성에 포함되어 `npm ci`로 함께 설치된다. [Kordoc 공식 저장소](https://github.com/chrisryugj/kordoc)의 Node API를 이용하며 별도 Kordoc 서버나 API 키는 필요하지 않다.

기존 `DATABASE_URL`, `IEUM_STORAGE_PROVIDER=neon`, `AWS_ENDPOINT_URL_S3`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `IEUM_STORAGE_BUCKET`, `IEUM_SESSION_SECRET`, `BIZROUTER_API_KEY`, `BIZROUTER_MODEL`을 그대로 사용한다. 브라우저에 저장소 비밀키를 전달하지 않고 서명된 주소로 직접 업로드한다. 연결값 위치와 CORS 안내는 [Neon 프로토타입 설정](./PROTOTYPE-NEON-SETUP.md)을 참고한다. 추가 SQL 마이그레이션은 필요하지 않다.

파일은 10MB 이하, 설명 자료는 최대 10개이다. PDF·HWP·HWPX·DOCX·XLS/XLSX·PPTX와 TXT·CSV를 지원한다. 문서 본문은 최대 20만 자, 페이지·섹션은 최대 150개, 한 번에 AI로 보내는 본문은 합계 6만 자이다. AI 범위를 줄일 때는 읽은 본문 미리보기에서 필요한 부분만 남긴다. 원본 파일은 변경하지 않는다.

현재 OCR은 사용하지 않는다. 스캔 PDF·이미지 문서는 OCR을 처리한 문서로 올리거나 본문을 직접 작성한다. 암호·DRM 문서는 해제된 파일이 필요하다. `.npmrc`에서 불필요한 GPU 런타임 다운로드를 건너뛰며, Vercel 배포에는 사용하지 않는 OCR 네이티브 엔진을 제외하고 PDF용 정적 한글 글꼴을 포함한다.

업무대행은 수행 기록·생산 문서·일정·체크리스트를 공유한다. 업무 기준 수정, 최종 검토 승인 및 원담당자의 반기 성과 제출·평가는 대행 범위에 포함하지 않는다.

## 검증 결과 (2026-11-06)

- 전체 단위·도메인 회귀검증과 TypeScript 검사, 배포 빌드 통과.
- Kordoc의 실제 HWPX·XLSX·PDF·TXT 본문 추출 확인. 손상 문서·빈 파일·본문 한도 거절 확인.
- 실제 BizRouter로 두 문서의 요약·원문 인용·설명 초안 반환 확인.
- 격리된 로컬 3001 서버에서 파일 업로드·추출·원자 연결, 대행 승인 전 접근 거절, 부서장 승인, 대행 수행, 기록 보존, 타 부서 동일 분장표 및 실제 다운로드 통합검증 12개 통과.
- 브라우저에서 파일 선택 → 본문 읽기 → AI 초안 적용 → 대행자 조직도 선택 → 업무 등록 → 부서장 승인 → 대행자 개인업무 표시 → 절차 완료까지 확인.
- 브라우저 PDF 다운로드 확인. XLSX 읽기 검증, PDF 한글 추출과 여러 페이지의 표 배치 확인.

검증 데이터는 `.qa-data/description-deputy-preview`에 격리했으며 실제 Neon 업무 데이터를 수정하지 않았다. `tests/http-description-delegation.mjs`는 로컬 3001 전용으로 실행하며 기본 실행은 실제 AI를 한 번 호출한다. 기존 AI 결과가 있으면 `--skip-ai` 옵션으로 재사용하며 중복 유료 호출을 막는다.
