# 처리 대기 배지 기준

메뉴 배지는 서버가 이미 권한에 따라 내려준 데이터 안에서 현재 사용자가 처리할 수 있는 요청을 셉니다. 보기 권한만 있는 항목은 승인 대기에 포함하지 않습니다.

| 메뉴 | 집계 기준 |
|---|---|
| 공통업무 | 본인이 승인 가능한 배포 요청, 팀장이 개인에게 배정할 업무, 본인이 단위업무에 등록할 업무 |
| 배정·승인 관리 | 기본 진입 부서인 본인 부서의 팀 배정 대기. 관리자도 기존 부서 범위를 유지하며 전 부서 총계가 아님 |
| 인수인계 | 해당 업무 소속 부서장이 승인·반려할 수 있는 새 인수인계 요청 |
| 성과·평가 | 제출 후 미평가 계획 중 본인 제외, 계획 당시 부서 권한과 제출 근거·보완 상태를 충족한 계획 |
| 업무대행 | 본인이 검토 가능한 요청. 여러 세부업무를 묶은 요청은 화면 카드와 같이 배치 1건 |

관리자는 공통업무 화면에서 전체 부서의 팀별 개인 배정을 처리할 수 있어 해당 대기는 공통업무 배지에 표시합니다. 인수인계·업무대행의 최종 승인 권한은 관리 권한과 구분하며, 관리자가 단순히 조회할 수 있다는 이유로 승인 대기를 표시하지 않습니다. 구형 인수인계는 현 화면에서 승인 작업을 제공하지 않으므로 포함하지 않습니다.

잠긴 업무분장의 배정·등록은 대기 배지에서 제외합니다. 팀장은 팀의 개인 배정 대기와 자신의 개인 등록 대기를 함께 확인합니다. 메뉴의 접근성 이름에 처리 대기 건수를 포함하며 모바일 메뉴 버튼에는 합계 표시와 점을 제공합니다.

인수인계와 평가의 판단은 화면과 배지가 공용 함수를 사용합니다. 부서장 인수인계 승인 검사는 서버도 같은 함수를 사용합니다. 성과 평가 명령의 입력 점수·합계 검증은 서버에서 계속 수행합니다.

부서장 요약은 ‘내 승인 대기’로 표시합니다. 인사이동 전에 참여했던 다른 부서의 미처리 요청은 관련 요청 수로 안내하며, 승인 권한이 없으면 ‘검토 및 승인’ 대신 ‘상세 보기’로 표시합니다. 참여 이력 자체는 숨기지 않습니다.
