# M10 상세 주소와 브라우저 이력

- 기존 `#personal` 등 메뉴 주소를 유지하고 `#personal/task/<id>/<tab>`으로 상세와 탭을 공유합니다. 생략되거나 알려지지 않은 탭은 개요로 정규화합니다.
- 개인업무·홈·일정·부서 화면의 상세 열기는 중앙 경로를 사용합니다. 개인업무의 수정 진입은 수정 모드를 전달합니다. 새로고침·공유 주소는 보기 모드로 시작합니다.
- 상세 열기는 이력을 추가하고 탭 전환은 같은 이력을 교체합니다. 앱이 연 상세의 닫기는 직전 항목으로 복귀하며, 직접 붙여 넣은 주소의 닫기는 현재 메뉴로 교체합니다.
- 이력 상태는 Next의 기존 값을 보존하며 앱 전용 영역에 기록합니다. 뒤로가기 취소는 앱이 관리한 이력 번호로 복귀하여 목록 주소를 상세 주소로 덮어쓰지 않습니다. 외부에서 만든 알 수 없는 이력에는 주소 복원 방식으로 대응합니다.
- 로그인 전 북마크를 유지합니다. 시작하기는 로그인 영역으로 스크롤하고 상세 주소를 바꾸지 않습니다. 명시적인 역할 전환·로그아웃은 상세 주소를 제거합니다.
- 업무 접근 권한은 기존 서버 응답과 TaskPanel 검사를 그대로 사용합니다. 접근 불가 주소는 안내를 표시하고 업무 제목을 노출하지 않습니다.
- 내부 탭 전환은 보존되는 업무 초안을 유지하고 사라지는 하위 입력을 확인합니다. 외부 브라우저 이력 이동은 전체 미저장 확인을 거치므로 뒤 화면에 남아 있는 초안까지 추가 확인할 수 있습니다. 승인 뒤에도 보존되는 초안을 임의로 저장됨 처리하지 않습니다.

검증 결과는 주 점검표에 기록합니다.
