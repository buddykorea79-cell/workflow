# 단위업무가 없는 사용자의 공통업무 등록

개인업무와 공통업무 화면은 같은 `CommonRegistrationModal`을 사용합니다. 단위업무 이름·업무 범위 입력은 기존 단위업무 등록창과 `UnitFormFields`를 공유합니다.

단위업무가 없으면 같은 창 안에 새 단위업무 입력을 펼칩니다. 단위를 저장한 응답에서 실제 ID를 확인해 선택하고, 이어 공통업무를 세부업무로 등록합니다.

두 서버 명령은 별도 저장으로 유지합니다. 단위업무는 다른 세부업무도 담을 수 있는 독립 항목이며, 두 번째 등록이 충돌하거나 배정 권한이 바뀌어 실패하더라도 사용자가 작성한 단위를 보존하는 편이 안전합니다. 실패 안내와 현재 선택을 유지하고 등록만 다시 시도합니다. 생성 후 추가 입력은 같은 단위의 수정 명령으로 저장하여 중복 생성을 방지합니다.

- 단위 생성·수정과 공통업무 등록은 각각 올바른 대상 버전을 검사합니다.
- 저장 중 입력·선택은 유지하고, 제출 이후 추가한 초안이 있으면 창을 자동으로 닫지 않습니다.
- 변경한 입력을 닫을 때 기존 미저장 확인을 거칩니다.
- 단위 생성 폼과 등록 폼을 분리하여 아직 선택할 단위가 없다는 이유로 단위 생성이 막히지 않게 합니다.
- 서버는 본인 배정, 활성 개인 단위, 같은 부서, 업무분장 작성 권한을 계속 검사합니다.

자동 검증과 실제 화면 결과는 `docs/REVISION-CHECKLIST-2026-11-07.md`에 기록합니다.
