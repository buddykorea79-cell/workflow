## 적용 후 결과

- 전체 660개 테스트·타입 검사·빌드 통과 후 같은 격리 데이터와 역할로 측정했다. 스크롤이 움직이는 경우 `getBoundingClientRect().top + scrollY`로 문서 상단 좌표를 사용했다.
- 도움말을 숨긴 일상 사용 화면은 기존보다 개인업무 72px, 공통업무 배정 목록 약49px, 인수인계 약292px, 성과 약139px 위에서 목록이 시작한다.
- 첫 방문에는 요청대로 교육 설명을 펼친다. 공통업무는 원래 하단에 있던 지표 설명을 목록 위로 옮겨 첫 방문 목록이 약214px 아래로 내려간다. 숨긴 뒤에도 짧은 중앙 제출기한 범례와 ‘자세히’는 항상 남는다. 최초 화면이 모두 짧아졌다고 해석하지 않는다.
- 개인업무 접기→새로고침에서 접힘, 숨기기→새로고침에서 숨김을 확인했고 제목의 도움말 버튼으로 다시 펼쳤다. 숨긴 직후 초점도 제목 도움말 버튼으로 돌아왔다.
- 송주무관이 숨긴 인수인계 설명은 별도 계정인 최과장에게 처음부터 펼쳐져 사용자별 설정이 분리됨을 확인했다.
- 인수인계 승인 대기 문장·건수·요청 카드와 공통 승인 전 미접수 안내는 도움말을 숨겨도 남았다. 부서 담당자에게 새로고침·인수인계 요청·남은 역할 정리·긴급 인사이동 네 버튼이 계속 표시됐다. 실제 승인이나 이관은 실행하지 않았다.
- 부서 담당자 1440×900에서 네 버튼의 오른쪽 끝은1408px로 화면 안이다. 375×812에서는 2열 두 줄(왼쪽16px, 오른쪽344px)로 배치되고 본문/스크롤 폭360px가 같았다. 부서장 모바일 도움말도 오른쪽344px로 잘리지 않았다.
