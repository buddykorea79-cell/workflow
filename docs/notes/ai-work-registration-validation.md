# AI 업무등록 검증

2026-11-08. 운영 DB·실제 BizRouter를 호출하지 않고 격리 QA에서 검증했다. QA 서버는 자식 환경의 BizRouter 키를 빈 값으로 고정하며, 분석 화면의 모델 응답은 루프백 프록시의 합성 응답이다.

## 자동 검증

신규 AI 도메인 15개, 서버 10개, UI·초안 9개, 명령 응답·요청 크기 6개를 포함한 전체 763개 테스트와 타입 검사를 통과했다. 서버 테스트는 실제 Kordoc HWPX 추출과 모의 BizRouter 요청·응답을 결합한다. AI 출력의 사실성이나 운영 모델 품질을 측정한 결과는 아니다.

- 항목별 이름·설명·마감일·수량·크기 검증, 마지막 항목 오류의 전체 미반영
- 본인 소속·담당자·활성 검토자·확정 부서·비공개 첨부 소유권·파일 무결성·분석 전후 권한
- 단일 감사 기록·개별 생성 버전·기존 생성 동작 유지
- 응답 유실 뒤 같은 등록 ID 재시도, 다른 전송 ID, 변경된 내용 거절, 이력 보존
- 분석·저장 중 추가 입력, 미적용 분석 결과 닫기 보호, 부서 확정 뒤 기존 요청 확인, 성공 후 추가 초안 보존
- 다른 탭의 계정 변경 응답·불완전 응답의 완료 처리 차단, 실제 요청 바이트 제한

## 실제 브라우저

주황색 AI 업무등록이 두 추가 버튼 앞에 있고, 즉시 열린 창에 담당자·검토자·기본 4단계가 표시됐다. 설명 입력과 합성 TXT 파일 업로드 뒤 실제 문서 추출 224자를 확인했다. 추출 본문은 편집 가능하고 분석 자료가 업무에 자동 첨부되지 않는다는 안내를 제공한다.

2.5초 지연 합성 AI 응답을 기다리는 동안 설명에 추가 입력을 했다. 입력을 유지하면서 새 결과를 별도로 표시했고, 결과의 단위업무·세부업무·주요내용을 먼저 펼쳐 볼 수 있었다. 2단위·3세부업무의 주요내용을 직접 수정했다. 빈 날짜 3개는 입력칸별 한국어 오류를 표시하고 첫 날짜 칸으로 초점이 이동했다. 375px에서 본문 폭 375px, 모달 내용·스크롤 폭 모두 345px로 가로 넘침이 없었다. 초안 복사와 닫기 전 확인도 점검했다.

브라우저 도구는 네이티브 date 입력의 날짜 조작을 완료하지 못했다. 따라서 **달력 선택부터 최종 등록 버튼까지 전체 수동 성공을 주장하지 않는다**. 날짜 입력·전송·저장 중 추가 입력·결과 불명 재시도의 UI 콜백은 자동 테스트로, 실제 저장·응답 유실은 아래 HTTP로 보완했다. 제품의 날짜 입력을 시험 편의 때문에 다른 방식으로 바꾸지 않았다.

## 실제 로컬 HTTP 저장

`.data/ai-http-check.mjs`에서 로컬 저장소임을 확인한 뒤 동일한 합성 미리보기와 명시 날짜를 전송했다.

1. 마지막 업무의 날짜를 비운 요청은 422, 단위·업무 수는 그대로였다.
2. 정상 요청은 서버에 저장된 뒤 프록시가 응답만 502로 교체했다.
3. 같은 importId·내용과 새 requestId로 재전송하자 200·빈 변경 목록이며 revision·항목 수가 그대로였다.
4. 생성된 단위업무 2개·세부업무 3개, 성공 감사 기록 1건을 확인했다.
5. 수정한 주요내용과 2026-11-30/12-01/12-02 날짜, 본인 담당·소속 부서장 검토·기본 4단계·절차 일정 공란·생성 rev 1을 확인했다.
6. 같은 importId의 내용을 바꾼 요청은 409로 거절했다.
7. QA의 실제 AI 생성 경로는 AI_NOT_CONFIGURED 503으로 외부 호출 없이 차단됨을 확인했다.

결과: `.data/ai-http-result.json`. 이 생성 데이터는 격리 QA 파일에만 남는다.

### 최종 화면 보완 확인

격리 QA 화면의 ‘새 분석 결과로 바꿀까요?’ 확인창에서 ‘기존 내용 유지’는 편집한 업무 이름을 유지했고, ‘새 결과로 바꾸기’는 선택한 미리보기만 교체했다. 입력 설명은 두 경우 모두 유지됐다. 등록된 ‘품질 점검 계획 수립’ 상세에서 수정한 주요내용, 2026-11-30 마감, 송주무관 담당을 확인했다. 1440px에서 본문 폭1425px로 가로 넘침이 없다.

확인 중 발견한 신규 업무 완료 기준의 잔여 ‘체크·결과물’ 문구는 일괄 등록에만 ‘필수 절차 수행 및 검토 완료’로 수정했고, 기존 개별 등록 기본값을 유지하는 회귀 검사도 통과했다. 복사본의 주기·중요도는 한국어로 정리했다.
