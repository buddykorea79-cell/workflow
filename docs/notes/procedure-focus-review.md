# 절차 작성과 절차도 화면 점검 (2026-11-08)

- 상세 탭을 업무 개요 → 관련 근거 → 절차 → 일정·수행 → 성과 → 예산·집행 순으로 정리했습니다. 해당 업무의 월간 계획 탭은 마지막에 유지합니다.
- 절차 상단의 `AI로 절차·절차도 작성`에서 기존 BizRouter 분석을 엽니다. 업무 개요와 개요 첨부파일을 우선 분석하고 선택한 관련 근거로 보완하는 입력 계약을 유지합니다. 개인업무 목록의 `AI 업무등록`은 단위·세부업무 초안을 만드는 별도 기능입니다.
- 저장하지 않은 개요·근거·절차, 업로드/저장 진행, 충돌 및 수정 권한 제한을 확인한 뒤 진입합니다. 사유는 버튼과 연결된 안내로 표시합니다.
- 적용된 절차도를 절차 편집 영역 첫 부분에 항상 표시하고 스크롤 중 고정합니다. 별도 확대 창, 키보드 선택, 선택한 절차 편집 위치로 이동을 제공합니다. 화면 크기가 바뀔 때만 자동으로 도표를 다시 맞춥니다.
- 사용 설명의 탭 순서와 AI 진입 방법도 함께 갱신했습니다.

## 검증

- 전체 자동 테스트 805개 통과, 배포 빌드 및 TypeScript 검사 통과, CSS 감사 보고서 일치, diff 공백 검사 통과.
- 격리된 로컬 QA 데이터로 1280×900과 375×812에서 확인했습니다. 운영 데이터는 변경하지 않았습니다.
- 데스크톱 → 모바일 → 데스크톱 전환 후 모든 도표 노드가 캔버스 안에 표시됩니다. 모바일 마지막 절차 이동 시 카드 상단 447px, 고정 도표 하단 426.7px로 겹침 없이 표시됩니다.
- 확대 창의 Escape는 확대 창만 닫고 확대 버튼으로 초점을 돌립니다. 기존 절차와 규칙 기반 초안 모두 선택한 편집 위치로 이동합니다. 미저장 초안 종료 확인도 유지됩니다.
- 절차 수정 → 저장·절차도 반영 → 새로고침 후 유지, 저장 전 AI 진입 제한을 실제 화면에서 확인했습니다.
- 외부 유료 AI 호출은 실행하지 않았습니다. BizRouter 및 Kordoc 입력·추출·교체 계약은 관련 자동 테스트 51개와 소스 검토로 확인했습니다.
