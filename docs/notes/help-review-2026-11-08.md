# 개인업무 안내와 도움말 점검 — 2026-11-08

## 반영 내용

- 개인업무의 중복 계층 설명 박스를 삭제하고 제목 아래 문구를 “단위업무는 업무 묶음, 세부업무는 실제 수행할 과제입니다.”로 변경했다.
- 개인업무 도움말은 버튼을 눌렀을 때만 안내창으로 열리도록 했다. 업무 만들기, 두 AI 기능의 차이, 절차·일정·성과 기록, 수정 권한을 안내한다.
- 화면별 도움말 다시 보기가 현재 표시되지 않은 조건부 안내까지 복원하도록 수정했다. 기존에는 현재 마운트된 안내에만 복원 요청이 전달되어 다른 보기의 숨긴 안내가 복원되지 않았다. 사용자별 설정과 복원 이후의 개별 숨김은 유지한다.
- 성과평가 도움말을 직원/평가자 역할별로 구분하고 중요도에 따른 비중 제안, 최소 1점·합계 50점, 저장과 제출의 차이, 참고 파일을 설명했다.
- 사용 안내의 실제 탭 이름·순서, 중요도, 기존 체크리스트 안내, 인수인계·대행 종료 설명을 현재 기능에 맞췄다.

## 검증

- 전체 자동 테스트 818건 통과, Next.js 프로덕션 빌드 통과, 타입 검사 및 CSS 사용 현황 검사 통과.
- 도움말 회귀 테스트 7건 추가: 조건부 안내 복원, 복원 후 재숨김, 사용자 구분, 저장소 차단 시 동작, 개인업무 기본 화면, 안내창 열기·닫기와 업무 상태 보존.
- 로컬 격리 데이터로 실제 브라우저 확인:
  - 개인업무의 정확한 부제, 기존 박스 제거, 도움말 열기·닫기·Escape 및 호출 버튼으로 포커스 복원.
  - 공통업무 전체 배정표의 추가 배포 안내 숨기기 → 업무별 보기에서 도움말 다시 보기 → 배정표로 복귀했을 때 안내 복원.
  - 공통업무 도움말 접기 상태의 새로고침 후 유지, 필수 범례 숨김 시 요약 유지, 자세히로 재확장.
  - 인수인계 도움말 2종의 숨기기·접기·다시 보기와 수정 문구 확인.
  - 업무 담당자와 부서장으로 전환하여 서로 다른 성과평가 안내 확인.
  - 전체 사용 안내의 역할별 안내, 세부업무 단계 탭, 비중 FAQ 펼침 및 닫기 확인.
  - 375×812 화면에서 개인업무 도움말이 가로 넘침 없이 표시되고 닫기 버튼에 접근 가능함을 확인.
- 평가 점수 안내의 조건부 복원은 자동 회귀 테스트와 소스 검토로 확인했다. 수동 점검 데이터에는 등록된 반기 성과가 없어 해당 안내의 표시 조건을 만들기 위한 성과 저장·제출은 실행하지 않았다.
- 점검 중 운영 데이터 변경 및 유료 AI 호출 없음.
