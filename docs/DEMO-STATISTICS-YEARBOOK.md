# 두 업무 담당자의 통계연보 시연

로그인의 **업무 담당자 1**은 송주무관, **업무 담당자 2**는 같은 부서의 조주무관으로 시작합니다. 이 통계연보 시연에서는 수신자로 혁신행정담당관실 **임주무관**을 직접 선택합니다. 실제 권한은 모두 **업무 담당자**이며 새로운 권한을 만들지 않습니다.

| 시연 구분 | 계정 | 소속 | 시연에서 맡는 일 |
| --- | --- | --- | --- |
| 업무 담당자 1 | 송주무관 (`u-support-member`) | 데이터정보화담당관실 · 데이터팀 | 통계연보 발간 총괄, 공통 자료 요청 작성 |
| 수신 담당자(직접 선택) | 임주무관 (`u-innovation-member`) | 혁신행정담당관실 · 혁신팀 | 배정받은 통계 자료 작성·확인·제출 |

## 준비된 자료

업무 담당자 1의 개인업무에는 **통계 간행물 발간 → 행정안전 통계연보 발간**이 있습니다. 발간 총괄 업무의 목적·절차와 시연용 작성 안내를 담았습니다. 관련 안내는 가상 자료이며 실제 법령·기관 지침이나 실제 제출 의무가 아닙니다.

같은 이름의 공통업무가 **데이터정보화담당관실 부서장 승인 대기**로 준비되어 있습니다. 대상은 혁신행정담당관실 한 곳입니다. 아직 배부되거나 임주무관의 세부업무로 등록되지는 않았습니다. 임주무관에게는 수신 업무를 넣을 빈 **통계 간행물 발간** 단위를 준비했습니다.

발간 총괄 개인업무와 부서 공통 자료 요청은 각각의 기록입니다. 현재 구조에서 개인업무 수정이 공통 요청을 자동으로 덮어쓰지는 않습니다.

## 시연 순서

1. **업무 담당자 1**로 로그인합니다. 개인업무의 발간 업무를 열어 목적·근거·절차를 살펴보고, 공통업무·지시사항에서 통계연보의 승인 대기를 확인합니다.
2. 데이터정보화담당관실 **부서장 최과장**으로 전환합니다. 공통업무에서 **행정안전 통계연보 발간**의 배포 요청을 검토·승인합니다.
3. 혁신행정담당관실 **부서 담당자 강담당**으로 전환합니다. 배부·승인 관리에서 해당 공통업무를 **혁신팀 · 박팀장**에게 배부합니다.
4. 혁신행정담당관실 **팀장 박팀장**으로 전환하여 **임주무관**을 수행 담당자로 배정합니다.
5. 역할 선택에서 **업무 담당자 2**를 누른 뒤 부서를 **혁신행정담당관실**, 시연 계정을 **임주무관**으로 바꾸어 로그인합니다. 개인업무의 공통업무 등록 대기에서 해당 업무를 **통계 간행물 발간** 단위에 등록합니다.
6. 임주무관이 자료를 작성·확인하고 혁신행정담당관실 부서장이 검토합니다. 업무 담당자 1은 공통업무에서 대상 부서의 배정과 진행 현황을 확인합니다.

부서 업무분장을 확정하여 배정이 잠긴 경우 해당 부서장이 **부서 업무 관리**에서 재작성을 허용한 뒤 계속합니다. 시연 추가 스크립트는 기존 승인·잠금·평가를 임의로 초기화하지 않습니다.

## 기존 저장소에 추가

새 로컬 저장소는 기본 시드에 시연을 포함합니다. 기존 로컬 또는 Neon에는 아래 스크립트로 추가합니다. 스크립트는 기본적으로 **미리보기만 수행**합니다.

```powershell
node --env-file=.env.local --import tsx scripts/setup-statistics-demo.ts
```

미리보기의 `workspaceId`를 확인한 다음 DB에 적용합니다. 아래 `development`는 실제 미리보기 값으로 맞춥니다.

```powershell
node --env-file=.env.local --import tsx scripts/setup-statistics-demo.ts --apply --expect-workspace development
```

로컬 저장소만 사용하는 경우 `--apply`로 적용하며 적용 전 백업을 만듭니다. 기존 계정·업무·파일·수행 기록은 변경하지 않고 단위업무 2개, 총괄 세부업무 1개, 승인 대기 공통업무 1개와 알림·추가 로그만 넣습니다. 같은 저장소에 다시 실행해도 시연이 중복되거나 진행한 승인이 초기화되지 않습니다. 이미 같은 ID나 단위명이 있으면 덮어쓰지 않고 확인 메시지를 반환합니다.
