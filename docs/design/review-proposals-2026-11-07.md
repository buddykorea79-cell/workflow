# 안내 문구와 역할별 메뉴 변경 제안

평가 문서 D2·D7은 “표를 나에게 보여주고 승인받은 뒤 2단계를 진행한다”라고 명시합니다. 아래 제안은 사용자에게 검토받았으며, 2026-11-07에 전체 적용 승인을 받았습니다.

## D2 안내 문구

교육용 설명은 접기·다시 보기와 사용자별 상태 기억을 제공합니다. 현재 상태와 경고·오류는 항상 표시합니다. 산식·권한·이력 보존 등 필요한 세부 설명은 펼침 안에 보존합니다.

| 위치·현재 설명 요지 | 제안 문구 | 분류 |
|---|---|---|
| 개인업무 계층 안내 | 단위업무에 세부업무를 묶어 관리하세요. | 교육용 |
| 공통업무 작성·배포 절차 | 부서장 승인 후 팀과 담당자를 배정합니다. | 교육용 |
| 공통업무 역할별 흐름 | 부서 접수 → 팀 배정 → 개인 배정 → 등록·수행 | 교육용 |
| 추가 배포 안내 | 대상 부서 추가는 업무별 보기에서 진행하세요. | 교육용 |
| 진행률·지연 지표 | 진행률은 절차 완료율이며, 지연은 제출기한 기준입니다. | 교육용 |
| 인수인계 남은 역할 | 지원·검토·총괄 역할도 후임에게 이관할 수 있습니다. | 교육용 |
| 긴급 이동 | 담당자가 정해지기 전에는 부서 보관으로 업무를 이어갑니다. | 교육용 |
| 인계 승인 대기 | 승인 전까지 현재 담당자가 업무를 수행합니다. | 상태 |
| 성과 입력·평가 절차 | 성과를 작성하고 업무 비중 50점을 정해 제출하세요. | 교육용 |
| 업무 비중 미설정 | 업무 비중을 합계 50점으로 설정해 주세요. | 상태 |
| 단위업무 구성 변경 | 단위업무가 변경되어 업무 비중을 다시 설정해야 합니다. | 경고 |
| 성과 제출 완료 | 제출했습니다. 평가 전에는 회수하여 수정할 수 있습니다. | 상태 |
| 평가 확정 | 평가가 확정되어 성과와 업무 비중이 보존됩니다. | 상태 |
| 반기 평가 각주 | 반기 평가는 단위업무별 점수를 합산해 50점으로 계산합니다. | 교육용 |

## D7 메뉴 구성

기존 권한은 유지하며 메뉴를 아래 네 그룹으로 묶습니다. 업무분장표의 상단 빠른 접근은 유지하는 안입니다.

| 역할 | 내 업무 | 협업 | 부서 관리 | 조직·시스템 |
|---|---|---|---|---|
| 업무 담당자 | 홈·개인업무·일정 | 공통업무·대행·인수인계 | 성과·평가·업무분장표 | 조직·구성원 |
| 팀장 | 홈·개인업무·일정 | 공통업무·대행·인수인계 | 성과·평가·업무분장표 | 조직·구성원 |
| 부서 담당자 | 홈·개인업무·일정 | 공통업무·배정·승인·대행·인수인계 | 예산·성과·평가·업무분장표 | 조직·구성원 |
| 부서장 | 홈·일정 | 공통업무·대행·인수인계 | 부서 업무·업무분장표·예산·성과·평가 | 조직·구성원 |
| 관리자 | 홈·개인업무·일정 | 공통업무·배정·승인·대행·인수인계 | 부서 업무·업무분장표·예산·성과·평가 | 조직·시스템 관리 |

- 내 업무는 항상 펼칩니다.
- 협업·부서 관리는 처리 대기가 있거나 현재 화면을 포함하면 펼칩니다.
- 조직·시스템은 기본으로 접습니다.
- 처리 대기 배지는 메뉴에 표시하고 접힌 그룹에는 합계를 표시합니다.
- 사용 안내와 프로필은 하단에 둡니다. 모바일에도 같은 그룹을 적용합니다.

## D5 시연 설명

역할 중심 설명으로 바꾸는 안을 제안했으나, 사용자가 **기존 시연 설명 유지**를 선택했습니다. 따라서 기존 시연 순서와 설명은 변경하지 않습니다. 잔여 영어 표기와 계정 내부 ID 노출 정리는 별도로 진행합니다.
