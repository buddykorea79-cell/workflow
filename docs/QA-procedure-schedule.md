# 관련 근거 · AI 절차 · 일정 등록 검증

검증일: 2026-11-01 (Asia/Seoul)

## 구현

- 세부업무 탭: 업무 개요 → 관련 근거 → 절차 → 일정 등록 → 예산·집행.
- 법령·지침·생산 문서 등의 본문, 링크, 첨부파일 연결. PDF/TXT/CSV 본문 가져오기.
- 저장된 근거를 선택하여 BizRouter 구조화 응답으로 절차와 역할별 절차도 초안 생성, 원문 인용과 선행 관계 검증, 검토 후 적용.
- 회차와 절차별 일정·상세 내용의 별도 저장, 체크리스트·수행 결과·검토 완료.
- 완료 후 새로운 일정 등록, 완료 회차의 날짜·상세 내용·수행 결과 보존.

## 결과

- `npm test`: 152/152 통과.
- `npm run build`: TypeScript 검사 및 프로덕션 빌드 통과. `/api/procedure-generate` 포함.
- `node tests/http-procedure-schedule.mjs`: 격리 서버에서 7/7 통과.

HTTP 검증은 `.qa/procedure-schedule-20261101` 저장소와 3001 포트를 사용했다. 기존 저장소를 변경하지 않고 합성 단위업무·세부업무를 생성했다. TXT 첨부 및 생산 문서 연결, 재로그인 후 보존, 일정·상세 내용 저장, 담당자·타부서·회차 충돌 검증, 체크리스트·검토 완료, 완료 일정 변경 차단, 다음 회차 초기화와 이전 기록 보존을 확인했다.

BizRouter 테스트는 모의 응답을 사용했다. 키·모델 누락, 모델의 구조화 응답 지원, 원문에 없는 인용, 순환 관계, 필수 검토 누락, 불완전 응답·상위 서버 오류·취소, 인증·타 업무 근거·미저장 내용·업무분장 잠금을 검증했다. 실제 외부 API 호출은 수행하지 않았다.

## 검증 제한과 설정

- 실제 AI 사용에는 서버의 `BIZROUTER_API_KEY`와 `BIZROUTER_MODEL` 설정이 필요하다.
- 브라우저 화면 검증은 내장 브라우저의 로컬 접속 시간 초과 및 Windows 브라우저 URL 확인 실패로 중단되었다. 실제 화면 배치와 클릭 흐름은 확인하지 못했다.
- 파일 업로드와 PDF 추출은 기존 로컬 환경 지원 범위를 유지한다. 배포 환경 첨부는 비공개 저장소 연결이 필요하며 스캔 PDF OCR은 지원하지 않는다.
- 관련 근거·생산 문서를 업무 기준으로 수정하는 권한은 기존 업무분장 잠금을 따른다. 확정 후에도 일정과 회차의 수행 결과는 계속 입력할 수 있다.
