# 국가법령정보센터 검색 연결 설정

확인일: 2026-11-06. 온이음 접속 주소는 `https://on-ieum.vercel.app`이며, 프로토타입의 관련 근거 검색에 국가법령정보 공동활용 OPEN API를 사용합니다.

## 현재 확인된 연결 상태

2026-11-06에 확인한 신청정보는 **도메인 `on-ieum.vercel.app`, 서버 IP 공란**입니다. 로컬에 저장한 실제 OC로 공식 API를 호출한 결과는 다음과 같습니다. 인증키 값은 문서에 기록하지 않습니다.

| 환경·대상 | 확인 결과 |
| --- | --- |
| 로컬 → 법령 목록 | HTTP 200으로 응답했으나, 응답 본문은 사용자 검증 실패 |
| 로컬 → 행정규칙 목록 | HTTP 200으로 응답했으나, 응답 본문은 사용자 검증 실패 |
| Vercel → 법령·행정규칙 | `LAW_API_OC` 환경변수 설정·재배포 후 확인 필요. 아직 연결 성공으로 판단하지 않음 |

법령정보센터 응답에는 정확한 서버 IP와 도메인을 등록하라는 안내가 포함되어 있습니다. **HTTP 200은 통신 성공일 뿐, 법령 검색 인증이 통과했다는 뜻은 아닙니다.** 이 응답만으로 원인을 IP 공란 하나로 단정할 수는 없으므로, 실제 OC·신청 상태·서비스 권한·등록 도메인을 함께 확인합니다.

아래의 “IP 공란” 안내는 신청 양식이 공란을 허용한다는 설명입니다. **현재 설정으로 API 이용이 승인되거나 Vercel에서 정상 동작한다는 의미가 아닙니다.** Vercel에서 실제 검색한 결과를 기준으로, IP 미등록 허용 여부를 제공기관에 확인하거나 고정 외부 호출 IP가 필요한지 결정합니다.

## 신청 화면의 도메인과 IP

공개 신청 화면에서는 서버 IP에 필수 표시가 없고, 공개된 입력 검증 코드도 IP 미입력을 차단하지 않습니다. 그래서 처음 신청할 때 공란으로 제출할 수 있으나, 실제 호출 허용까지 보장하지는 않습니다. 이 프로젝트는 공란으로 등록한 상태에서 로컬 호출이 거절되었으므로, 위의 연결 상태와 다음 확인 절차를 함께 보세요. [공식 신청 화면](https://open.law.go.kr/LSO/usrJoin.do)

| 항목 | 온이음에 입력할 내용 |
| --- | --- |
| 시스템/홈페이지명 | 온이음 |
| 도메인 구분 | 도메인 있음 |
| 도메인 주소 | `on-ieum.vercel.app` — `https://`와 마지막 `/`는 제외 |
| 서버장비의 IP주소 | 현재 공란으로 등록됨. 실제 Vercel 호출 결과와 제공기관의 안내에 따라 보완. `0.0.0.0`을 전체 허용 값으로 임의 등록하지 않음 |
| 소개·주요 기능 예시 | 부서별 단위·세부업무, 업무분장, 수행 절차와 일정을 관리하는 업무관리 프로토타입 |
| 활용 목적 예시 | 사용자가 법령·행정규칙을 키워드로 검색하고 필요한 조문을 세부업무의 관련 근거에 인용하여 업무 절차 검토에 활용 |

`0.0.0.0`이 이 서비스에서 “모든 IP 허용”을 뜻한다는 공식 안내는 확인되지 않았습니다. 화면에 보인다는 이유만으로 전체 허용 값이라고 해석하지 않습니다.

공란 신청이 거절되거나 API에서 사용자 검증 실패와 IP·도메인 등록 안내가 나오면, 먼저 실제 OC와 등록 도메인을 확인하세요. 계속 실패하면 공동활용 사이트의 사용신청·이용문의에 **“Vercel 서버리스 프로토타입이라 외부 호출 IP가 유동적이며 도메인은 on-ieum.vercel.app입니다. IP 미등록 사용이 가능한가요?”**라고 확인하세요. 문의 번호는 공식 페이지 하단에서 최신 값을 확인할 수 있습니다. [공식 이용안내](https://open.law.go.kr/LSO/information/guide.do)

## Vercel의 IP를 한 개 골라 적으면 안 되는 이유

API는 사용자의 브라우저가 아니라 온이음 서버에서 호출합니다. Vercel의 기본 외부 호출 IP는 유동적이므로 한 번 조회한 IP를 영구 IP로 등록하면 이후 호출이 실패할 수 있습니다. `on-ieum.vercel.app`의 DNS 조회 결과는 앱에 접속하는 주소이며, 법령 API로 나가는 서버 주소를 대신하지 않습니다. 내 PC의 `192.168.x.x`, `10.x.x.x`, `127.0.0.1`도 배포 서버 IP로 사용할 수 없습니다. [Vercel 외부 연결 안내](https://vercel.com/academy/optimize-your-vercel-account/backend-egress)

법령정보센터에서 고정 IP 등록을 요구할 때만 다음 방법을 검토하세요.

1. Vercel에서 **프로젝트 → Settings → Networking → Static IPs**로 이동합니다.
2. `Manage Active Regions`에서 함수가 실행될 리전을 설정합니다.
3. 대시보드에 표시된 **외부 호출용 고정 IP 쌍**을 모두 복사해 법령 API 신청정보에 등록합니다.
4. 온이음을 다시 배포한 뒤 검색합니다.

Static IPs는 Pro·Enterprise에서 제공되는 유료 기능입니다. 필요한지 여부는 **실제 Vercel 호출 결과와 제공기관의 IP 등록 정책 확인 후** 결정합니다. 프로토타입이라는 이유만으로 필요 없다고 단정하지 않으며, 현재 작업에서는 Vercel 요금제나 네트워크 설정을 변경하지 않습니다. [Vercel 고정 IP 설정 순서](https://vercel.com/docs/networking/static-ips/getting-started), [지원 요금제·과금 안내](https://vercel.com/docs/networking/static-ips)

## 신청할 API와 OC 확인 위치

국가법령정보 공동활용 사이트에서 **인터넷** 서비스의 다음 항목을 신청합니다.

- 대한민국 현행법령: **목록 JSON, 본문 JSON**
- 현행 행정규칙: **목록 JSON, 본문 JSON**

API 인증키 `OC`는 신청 화면에서 직접 지정하고 중복 확인하는 값입니다. 신청 후 **마이페이지 → API인증키관리**에서 확인합니다. 이메일 주소의 앞부분을 임의로 넣거나 공공데이터포털의 `serviceKey`로 대체하지 말고, 이 사이트에서 신청·등록한 OC를 사용하세요. 사용 신청 상태와 조회하려는 법령종류의 권한도 함께 확인합니다. [공식 신청 화면](https://open.law.go.kr/LSO/usrJoin.do), [OPEN API 활용가이드](https://open.law.go.kr/LSO/openApi/guideList.do)

## 온이음에 설정하는 환경변수

추가할 변수는 서버 전용 **`LAW_API_OC` 하나**입니다. `NEXT_PUBLIC_`를 붙이지 않습니다. 이 값은 법령 API 호출 인증에 사용하며, 브라우저에 전달하지 않습니다.

### 로컬 개발

1. `D:\Workflow-Project\.env.local`을 엽니다.
2. 다음 항목에 **본인이 신청한 실제 OC 값**을 입력합니다. 아래 문구는 자리 표시자입니다.

   ```dotenv
   LAW_API_OC=신청한_OC_값으로_교체
   ```

3. 파일을 저장하고 실행 중인 로컬 서버를 종료한 뒤 `npm run dev`로 다시 실행합니다.
4. 로컬 온이음에서 키워드 검색을 시험합니다.

`.env.local`은 저장소에 포함하지 않습니다. API 키를 채팅이나 화면 캡처로 공유할 필요가 없습니다.

### Vercel 배포

1. Vercel 대시보드에서 **on-ieum 프로젝트 → Settings → Environment Variables**를 엽니다.
2. `Add Environment Variable`에서 이름을 `LAW_API_OC`, 값을 실제 OC로 입력합니다. 값 유형을 선택할 수 있으면 `Secret`을 선택합니다.
3. **Production**을 선택합니다. 미리보기 배포에서도 쓸 경우 **Preview**도 선택합니다.
4. 저장한 뒤 **Deployments → 현재 Production 배포의 메뉴 → Redeploy**를 실행합니다.
5. 배포가 완료되면 `https://on-ieum.vercel.app`을 새로고침하고 검색합니다.

환경변수 변경은 이미 실행 중인 배포에 소급 적용되지 않습니다. 반드시 새 배포가 필요합니다. Vercel에 저장한 값은 로컬 `.env.local`에도 자동으로 복사되지 않으므로 두 환경을 각각 설정해야 합니다. [Vercel 환경변수 안내](https://vercel.com/docs/environment-variables)

## 연결 확인 순서

1. 수정 권한이 있는 세부업무의 **관련 근거**를 엽니다.
2. 법령·행정규칙 검색에서 우선 `통계법`처럼 분명한 명칭으로 검색합니다.
3. 결과를 열어 시행일·발령정보와 조문을 확인합니다.
4. 필요한 조문을 골라 관련 근거에 넣고 변경사항을 저장합니다.
5. 같은 방법으로 행정규칙도 조회합니다. 법령만 되고 행정규칙이 실패하면 신청한 API 종류와 **본문 JSON** 권한을 확인합니다.

| 나타나는 문제 | 먼저 확인할 내용 |
| --- | --- |
| 연결 설정이 필요하다는 안내 | 현재 실행 환경의 `LAW_API_OC`, 오탈자, 저장 후 재시작·재배포 여부 |
| 인증·접근 실패 | OC 값, 신청 상태, 법령종류별 목록·본문 JSON 권한. IP 제한 안내가 있으면 위 IP 절차 확인 |
| 검색 결과 없음 | 짧은 키워드나 정식 법령명으로 다시 검색하고 법령/행정규칙 구분 확인 |
| 목록은 나오지만 본문이 안 열림 | 해당 종류의 본문 JSON 신청 여부와 원문 제공 상태 |
| 시간 초과·일시 오류 | 잠시 후 다시 시도. 반복되면 공동활용 사이트 공지 확인 |

가져온 내용은 선택 시점의 원문을 근거로 보관합니다. 법령이 개정되었는지는 원문 링크와 시행일을 확인하고 필요할 때 다시 가져오세요. AI가 만든 절차에서는 업무 개요와 붙임 파일을 우선 분석하고, 가져온 법령·행정규칙을 보완 자료로 참고합니다.
