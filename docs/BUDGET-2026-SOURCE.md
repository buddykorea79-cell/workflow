# 2026년 예산 자료의 추출 범위와 검증

사용자가 제공한 **2026년 예산 개요.pdf**의 **「참고 2 2026년도 세출예산 세부내역」**을 검색용 예산 목록으로 변환했습니다. 원문은 27쪽이며, 데이터 범위는 **PDF 15~25쪽 / 인쇄면 11~21쪽**입니다. 원본 PDF는 저장소에 복제하지 않습니다.

## 생성 파일

- `data/budgets/2026-budget.json`: 최초 예산 목록, 원문 출처, 검증 결과
- `scripts/extract-budget-2026.py`: 같은 원문으로 JSON을 다시 생성하는 추출 스크립트

JSON은 `schemaVersion`, `year`, `source`, `validation`, `items`로 구성됩니다. 관리자가 등록·수정하는 예산 목록과 구분할 수 있도록 JSON의 `source.sha256`에 제공된 PDF의 SHA-256을 기록했습니다.

## 어떤 예산을 선택했는가

원문 상세표에는 `’25년 본예산(a)`, `’25년 추경`, `’26년 정부안`, **`’26년 확정(b)`**, 증감, 증감률이 나란히 있습니다. 이 중 **2026년 확정(b)** 금액만 `confirmedAmountWon`으로 사용합니다.

원문 금액 단위는 **백만원**입니다. JSON의 확정 예산은 원문 값에 **1,000,000을 곱한 원 단위 정수**입니다. 원문 금액 문자열은 `sourceAmount`, 원문 단위는 `sourceUnit`에 별도로 남깁니다.

예를 들어 `새마을운동지원`의 원문 정부안은 713백만원, 확정액은 3,763백만원입니다. 검색용 확정 예산은 **3,763,000,000원**으로 저장합니다. `공공부문 AI 서비스 지원(정보화)`의 확정 20,608백만원은 **20,608,000,000원**입니다.

세입예산, 예산 총괄, 분야·프로그램 요약과 신규사업·완료사업 설명 표는 세출 세부사업과 중복되거나 용도가 다른 자료이므로 검색 목록에 중복 등록하지 않았습니다. 일반회계와 지역균형발전특별회계의 상세 세출사업은 모두 포함했습니다.

## 보존한 계층과 식별

각 항목에는 다음 필드를 보존합니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 연도·회계·단위사업·세부사업 코드 및 전체 경로 해시로 만든 고유 식별자 |
| `year` | 회계연도 2026 |
| `account`, `accountCode` | 회계명·코드 |
| `field`, `fieldCode` | 분야명·코드 |
| `sector`, `sectorCode` | 부문명·코드. 원문 표현은 ‘부문’ |
| `program`, `programCode` | 프로그램명·코드 |
| `unitProject`, `unitProjectCode` | 단위사업명·코드 |
| `projectName`, `projectCode` | 세부사업명·코드 |
| `confirmedAmountWon` | 2026년 확정 예산, 원 단위 안전한 정수 |
| `sourceAmount`, `sourceUnit` | 원문 확정액 문자열과 단위 |
| `sourcePage`, `sourcePrintedPage` | PDF의 1부터 시작하는 페이지와 인쇄면 번호 |
| `active` | 최초 수록 시 모두 `true` |

세부사업 코드만으로는 항목을 구별할 수 없습니다. 예를 들어 특별회계의 동일한 코드 아래 자율·제주·세종 등의 구분을 포함한 서로 다른 명칭이 나옵니다. 이름이나 코드 하나로 합치지 않고 원문 행과 전체 계층을 보존했습니다.

## 검증 결과

| 항목 | 결과 |
| --- | --- |
| 상세 세부사업 행 | **308개** |
| 2026년 확정액이 양수인 행 | **285개** |
| 원문 확정액이 `-`인 행 | **23개**, 0원으로 보존 |
| 일반회계 | 277행 / **73,173,076,000,000원** |
| 지역균형발전특별회계 | 31행 / **3,732,472,000,000원** |
| 전체 확정액 합계 | **76,905,548,000,000원** |
| 원문 전체 확정액 | **76,905,548백만원**, 추출 합계와 일치 |
| 회계·분야·부문·프로그램·단위사업 소계 | **161개 모두** 하위 세부사업 합계와 일치 |
| 확정액 열 별도 추출 비교 | 상세표 11쪽 모두 일치 |
| 페이지 이미지 검토 | 상세표 PDF 15~25쪽 전체 렌더 후 계층·금액 열·줄바꿈·이어지는 행 확인 |

페이지별 세부사업 행 수는 PDF 15쪽부터 순서대로 **21, 24, 27, 29, 27, 39, 32, 32, 36, 24, 17개**입니다.

**원문 요약표의 사업 수와 상세표 행 수에는 차이가 있습니다.** 요약에는 세부사업 310개(일반회계 279, 특별회계 31)로 적혀 있으나, 상세표에서 확인한 독립된 세부사업 행은 308개(일반회계 277, 특별회계 31)입니다. 원문만으로 차이 2개의 원인을 확정할 수 없어 임의의 항목을 추가하지 않았습니다. 금액은 전체·회계별 합계와 모든 상위 소계가 정확히 일치합니다. 이 차이는 JSON `validation`에도 명시했습니다.

`-`를 0원으로 보존한 것은 **2026년 확정 예산이 0원인 원문 사업**이라는 뜻입니다. 사용자가 업무에서 지정하는 **비예산 사업**과 자동으로 같은 것으로 취급하지 않습니다.

## 재생성

Python에 `pdfplumber`가 설치된 환경에서 다음 명령을 실행합니다.

```powershell
python scripts/extract-budget-2026.py --input "C:\path\2026년 예산 개요.pdf"
```

페이지 이미지도 함께 생성하려면 `--render-dir .qa/budget-2026`을 추가합니다. 기본 출력 경로는 `data/budgets/2026-budget.json`이며 `--output`으로 변경할 수 있습니다.

스크립트는 페이지 수·표 제목·금액 형식·계층 들여쓰기·확정액 열·고유 ID·행 수·전체 및 회계별 합계·161개 소계를 검사합니다. 구조나 금액이 달라지면 오류로 중단합니다. 다른 판본이나 연도에 그대로 적용하여 조용히 잘못된 금액을 저장하지 않습니다.

관리자에서 수정한 목록을 이 스크립트의 출력으로 자동 덮어쓰지 않도록, 재생성한 원본 JSON의 검증 결과를 확인한 후 필요한 항목을 반영하세요.
