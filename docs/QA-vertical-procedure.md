# 세로 절차도·스크롤 보기 검증

검증일: 2026-11-09.

## 변경된 화면

- 절차 탭의 **크게 보기**와 업무분장표의 **절차도 보기** 팝업에 같은 문서형 절차도를 적용합니다.
- 담당자·협업·지원·검토 역할은 가로 열, 선행 관계에 따른 진행은 위에서 아래로 표시합니다. 실제 사용하는 역할의 열을 표시합니다.
- 제목 16px, 담당자 14px을 유지합니다. 긴 제목과 담당자 이름은 카드 안에서 모두 줄바꿈하며, 단계 수에 맞춰 전체 그림을 축소하지 않습니다.
- 긴 절차는 세로로, 좁은 화면에서는 역할 열을 가로로 스크롤합니다. 고정 역할 머리글은 이름을 최대 두 줄로 요약하고 카드에는 전체 이름을 표시합니다.
- 단계 번호·역할별 색상·선행 단계 번호와 화살표를 제공합니다. 분기·합류와 긴 카드를 반영해 연결선을 실제 카드 위치에서 그립니다.
- 업무분장표 팝업은 열자마자 큰 절차도를 표시하며 별도 확대 팝업은 없습니다. **절차 목록으로 보기**도 유지합니다.
- 절차 수정 화면의 작은 미리보기는 유지합니다. 큰 창에서 단계를 선택한 뒤 **선택한 절차로 이동**을 눌러야 편집 위치로 돌아갑니다. 닫기만 하면 편집 위치와 입력 내용은 바뀌지 않습니다.

## 검증 결과

- 전체 회귀 테스트 884개 통과, 실패 0개. 타입 검사와 최종 프로덕션 빌드 통과.
- 격리된 로컬 Chrome에서 12항목 통과. 데스크톱 1440×1050, 휴대폰 390×844, 낮은 화면 844×390으로 확인했습니다.
- 20단계의 긴 제목·여러 담당자·분기·합류를 포함한 모의 응답에서 글자 크기, 자연 줄바꿈, 카드 겹침 없음, 실제 연결 유지, 연결선의 다른 카드 관통 없음, 끝점 위치를 검증했습니다.
- 마우스 휠·PageDown·ArrowRight 스크롤, 고정 머리글, 마지막 단계와 닫기 버튼 접근, 페이지 가로 넘침 없음을 확인했습니다.
- 본인·다른 부서 조회, 오류 재시도, 닫은 창의 늦은 응답 무시, 빈 절차, Escape 후 초점 복귀와 큰 창의 명시적 편집 이동을 확인했습니다.
- 업무분장표의 최소 조회 API·기존 4열·소속 부서 기본값·상세 접근 권한은 유지했습니다.
- 브라우저 런타임 오류 0건, 외부 요청·AI 호출·업무 변경 요청 0건. 격리 로컬 저장 파일도 전후 동일합니다.
