# 가로 절차도·한 줄 업무 정보 검증

검증일: 2026-11-09. 이전 세로 절차도 표시를 대체하는 최종 화면입니다.

## 표시 방식

- 절차의 **크게 보기**와 업무분장표의 **절차도 보기** 팝업 제목은 **업무 절차도**입니다.
- 제목 바로 아래에 `부서명: … · 단위업무: … · 개인업무: …`를 한 줄로 표시합니다. 긴 정보도 줄바꿈 없이 가로로 확인합니다.
- 팝업 본문에는 절차도만 표시합니다. 중복 제목·설명·범례·절차 목록은 제거하고 닫기와 필요한 경우 선택한 절차로 이동만 유지합니다.
- 역할은 세로 행, 진행 단계는 왼쪽에서 오른쪽입니다. 왼쪽 역할·담당자 영역을 고정하고 카드에는 번호와 단계명을 표시합니다.
- 도표 높이는 창에 맞춥니다. 제목 글자 크기는 16px로 유지하고, 긴 제목이 행 높이를 넘으면 해당 열의 폭을 늘립니다. 화면을 넘을 때만 가로 스크롤을 사용합니다.
- 업무분장표에는 현재 저장된 절차 구조만 표시합니다. 기본 부서·4열·최소 조회 API·상세 권한은 유지합니다.
- 수정 중인 업무명·단위업무를 큰 창에 전달합니다. 지난 회차는 해당 정의 버전의 업무명·부서·단위를 사용하며, 조회할 수 없는 부서·단위 명칭은 ‘확인 필요’로 표시합니다.

## 검증 결과

- 전체 테스트 885개 통과, 실패 0개. 타입 검사와 최종 프로덕션 빌드 통과.
- 격리된 로컬 Chrome 브라우저 검증 12항목 통과. 1440×1050, 390×844, 844×390에서 업무분장표 팝업과 실제 절차 탭의 큰 창을 확인했습니다.
- 20단계·150자 제목·분기·합류·긴 담당자 이름으로 역할 행 정렬, 연결선 끝점, 카드 겹침 및 연결선 관통 없음, 전체 단계명 보존, 16px 글꼴을 검증했습니다.
- 도표와 모달 본문 모두 `scrollHeight <= clientHeight + 1`을 만족했습니다. 숨겨진 세로 내용 없이 가로 스크롤로 마지막 단계까지 도달합니다.
- 방향키·가로 휠·고정 역할 영역, 짧은 절차의 불필요한 스크롤 없음, 한 줄 업무 정보, 닫기 접근, Escape 초점 복귀를 확인했습니다.
- 조회 오류 재시도·늦은 응답 무시·빈 절차·큰 창의 선택 후 명시적 이동을 검증했습니다. 닫기만 하면 편집 위치를 바꾸지 않습니다.
- 브라우저 오류 0건, 외부 요청·AI 호출·업무 변경 요청 0건. 격리 로컬 저장 파일도 전후 동일합니다.
