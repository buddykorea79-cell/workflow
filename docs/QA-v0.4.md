## 브라우저 검증

시연 계정을 실제로 전환해 다음 흐름을 확인했습니다.

1. 김담당 총괄 계정: 업무 검색 → 전체 배정표 → 단계·부서 필터와 집계 일치.
2. 오담당 부서 담당자: '내 처리 대상'에서 분기 예산 업무를 데이터팀 김팀장에게 배정.
3. 김팀장: 배정받은 업무의 개인 담당자를 송주무관으로 지정.
4. 송주무관: 공통업무 화면에서 '공공데이터 품질 관리' 단위에 직접 등록.
5. 등록 대기 → 수행 전 전환, 단위업무 이름 및 0/4개 절차 표시.
6. '업무 수행' 버튼으로 연결된 세부업무 화면 열기.
7. '현황 새로고침' 후 마지막 조회 시각 갱신.
