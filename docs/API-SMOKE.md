# 로컬 API 통합 검증

검증일: 2026년 10월 31일, 한국 시간 기준

대상: `http://127.0.0.1:3000`의 Next.js API와 로컬 영구 저장소. 브라우저와 분리한 테스트 쿠키를 사용했으며, 기존 예제 업무는 변경하지 않았다. 가상 검증 업무 하나를 생성해 검증하고 폐기했다. 아래 결과는 실제 실행 결과이며 외부 서비스 연동 검증은 포함하지 않는다.

| 요청·확인 | 결과 |
| --- | --- |
| 부서담당으로 업무 생성 | 200, 작성 중 업무 생성 |
| 초안 설명 수정 | 200 |
| 초안 검토 요청 | 200 |

초기 요청에서 로컬 `Origin` 검사 불일치가 발견되어 백엔드에 전달했다. 위 통합 시나리오는 Origin 헤더를 생략한 로컬 테스트 클라이언트로 실행했다. 이후 수정본의 실제 브라우저 신규 업무 저장·인수 체크·수락이 성공한 결과는 [QA.md](QA.md)에 기록했다. 운영 Neon 인증·DB·Object Storage, BizRouter·법령 API, Vercel 배포·예약 실행은 이 검증 범위에 포함되지 않는다.
