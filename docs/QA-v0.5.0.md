# 온이음 v0.5.0 검증 기록

검증일: 2026-10-31

## 변경 사항

- 부서장 전용 업무 요약 및 직원별 단위·세부업무 조회 화면.
- 부서 업무분장 확정과 사유를 남기는 재작성 허용. 확정 버전의 스냅샷과 이력 보존.
- 분장 확정 중 업무 정의의 추가·변경·삭제와 배정 변경을 서버에서 차단. 진행률·실행 기록·성과 입력은 유지.
- 일반 사용자에게 소속 부서의 조직·구성원·권한 정보만 제공. 관리자는 전체 부서 조회 가능.
- 개인 세부업무의 절차·일정에서 PDF 및 법령·지침 본문으로 절차 초안을 만들고 역할별 흐름도로 확인·수정·저장.
- 관리자 구현 현황과 릴리스 기록을 v0.5.0으로 갱신.

## 화면 검증

1. 부서장으로 직원별 업무 요약과 부서 업무분장 화면을 확인했다.
2. 업무분장 확정 후 직원의 단위·세부업무 생성·수정·삭제 및 공통업무 등록 버튼이 잠기는 것을 확인했다.
3. 부서장이 재작성 사유를 입력하면 직원 편집이 재개되는 것을 확인했다.
4. 일반 사용자의 조직 화면은 소속 부서만, 관리자는 3개 부서의 16명 전체를 확인할 수 있었다.
5. 격리된 검증 데이터의 ‘정보화사업 정산 증빙 정리’에 지침 본문을 입력해 4단계 절차를 생성했다. 역할, 선행 단계, 출처 문단을 검토하고 기존 절차 교체 및 저장 후 파일에 반영된 것을 확인했다.
6. 역할별 흐름도 확대·축소 및 크게 보기 동작을 확인했다.
7. 포트 3000의 실제 앱을 v0.5.0 운영 빌드로 실행하고 부서장 화면을 확인했다.

## 지원 범위와 제한

- PDF는 로컬 서버에서 텍스트를 추출한다. 외부 AI 서비스로 문서를 전송하지 않는다.
- 텍스트 PDF를 지원하며, 스캔 이미지 PDF의 OCR은 아직 지원하지 않는다.
- 절차 생성은 규칙 기반 초안이다. 원문의 명시적 단계·업무 표현과 출처를 제시하고 사용자가 역할·순서·검토 단계를 확인한 후 적용한다.
- URL 입력은 출처 기록용이며 해당 주소의 본문을 자동 수집하지 않는다.
- PDF 제한: 10MB, 150쪽, 추출 본문 20만 자. 생성 절차 및 저장 전 검증에는 연결 오류·순환 관계 검사가 포함된다.
- 역할별 절차 구조는 korea100의 데이터 계약을 참고했다: https://github.com/hosungseo/korea100/blob/main/docs/data-contract.md
